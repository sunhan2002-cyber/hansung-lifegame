## 실제 연결과 확인

AvatarLayerAssets는 avatar_v4의 몸→피부→눈→머리를 읽는다. 피부/머리/눈을 하나씩 바꾸면 다른 선택 ID와 레이어가 유지된다. 체형이 바뀔 때는 외형 ID를 유지하고 몸과 노출 피부 위치만 함께 바뀐다.

청년 세 체형을 네 레이어로 실제 앱에서 먼저 확인한 뒤 전체를 포장했다. 검수에서 영아/노년의 손 피부 누락과 옷 색에 섞이는 마스크를 수정했다. 최종 648조합의 경로·alpha·발 위치·양쪽 눈 표시·양손 피부 변경 및 몸 18개의 생성 원본 대응을 확인했다. 대표 18개·시기별 36외형·실제 앱을 직접 확인했으며 모든 조합을 수동 미적 검수했다고 주장하지 않는다.

## 시연 절차

1. Android Studio에서 현재 브랜치의 app 실행 → 새 인생 → 모습. 피부·머리·눈을 하나씩 바꾸고 다른 선택과 세 시기 미리보기가 유지되는지 확인한다.

5. 종료 → 실제 선택 주마등 → 미래 로딩/취소/대체 → 기록증 → 지난 인생·칭호 재열람을 확인한다.

## 남은 제한과 미검증

- 실제 사용자 사진 생성 서버와 사진 얼굴 시트 픽셀 합성은 미연결이다. 예제/Fake를 실제 사진 생성 성공으로 보고하지 않는다.
- 과거 시기별 스탯 이력이 없어 주마등 체형은 마지막 체형을 쓴다(#43의 기존 제한).
- 실물 기기, 실제 생성 서비스, 미서명 Release 기기 설치, 10,000회 밸런스 시뮬레이션은 수행하지 않았다.
- 원격 push·PR 생성·메시지/노션 전송은 하지 않았다. 현재 결과는 로컬 브랜치의 실제 파일·APK·검증 문서다.
