**전용 경로 결말 비율 (main → 이 브랜치)**

| 경로 | 350판 비교군 | 200시드 무작위 | 200시드 지향 |
| --- | --- | --- | --- |
| 건강 | 54% → 54% | 49% → 43% | 93% → 84% |
| 운동능력 | 40% → 48% | 38% → 45% | 88% → 89% |
| 지력 | 86% → 90% | 90% → 89% | 60% → 65% |
| 사회성 | 48% → 46% | 40% → 41% | 94% → 93% |
| 경제력 | 40% → 44% | 43% → 42% | 95% → 96% |
| **행복** | **10% → 48%** | **7% → 46%** | 88% → 98% |
| **운** | **6% → 28%** | **14% → 30%** | 45% → 50% |

- 건강은 200시드 무작위에서 6%p 내려갔다. 어릴 때 선택을 따라 예술고 → 행복, 돌잡이 5만 원 → 운, 태권도 → 운동 경로로 가는 판이 생겼기 때문이다 (의도한 경로 상호작용). 비교군 350판에서는 그대로다.
- 판 하나에서 겪는 경로 사건 수(지향 정책 중앙값)는 5~7개에서 7~9개로 늘었다. 신규 사건 71개 중 67개가 2,800판 안에서 실제로 나왔다. 안 나온 4개는 조건이 드문 갈래다 (`path_fit_10` 운동부를 그만둔 뒤, `path_hap_12` 번아웃 회복 후, `path_hap_16` 웃음을 잃은 노년, `cross_12` 학자금 마지막 회차).
- 가족 빈도: 결혼한 판 52% → 52%, 첫 아이 25% → 23%, 혼자의 삶 27% → 32%.

**기기 확인** (에뮬레이터, 화면 캡처는 Git 제외 폴더 `scenario_review/play`)

1. 운 집중 판: 유년기 뽑기 3연속 → 주운 지갑(파출소) → 엘리베이터 30초 → 동창의 투자 → 노년 1년 차 '병원 대기실의 단골'에서 실제 사망 결과. 결말 화면에 '지갑 하나로 바뀐 인생', 요약 "운에 맡긴 삶 · 대학 진학 · 프리랜서 · 결혼 · 대표 업적: 행운의 연속 · 노년기에 마침", 원인 "잠결의 심장마비"가 표시됐다.

## 4. 시연 시드와 절차

앱은 지금 시드를 고를 수 없다 (`GameSession` 의 `runSeedFactory` 기본값이 현재 시각). 아래 시드는 `PeriodGameSession(runSeedFactory = { 시드 })` 에 앱과 같은 엔진 설정(`skipInfantFocus`, `guaranteeYearlyIncident`)을 쓰고, 초점은 목표 능력치가 가장 오르는 것으로 고른 결과다. 선택은 두 가지 방법으로 고른다.
- **지향**: 대표 결과에서 목표 능력치가 가장 오르는 선택지
- **무작위**: `Week9BalanceSimulationTest` 와 같은 `시드:사건:시기:해` 해시

고정 시드 시연 동선은 김선한 님 작업과 맞춘다.

- 결과 갈래: 신규 선택지 대부분이 결과 2갈래다. 선택지에는 "가능성 높음/반반쯤"이 숫자 없이 표시된다.
