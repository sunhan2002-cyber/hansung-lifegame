### 2. 외형 설정 · 사진(선택) · 성장 캐릭터 (F10-09, F10-10)

- 프로필에 **모습** 섹션 추가: 피부 3 · 머리 4 · 눈 3 중 고르면 영아 · 청소년 · 청년 미리보기가 바로 바뀐다. 사진 없이 바로 시작할 수 있다.
- **사진으로 얼굴 만들기(선택)**: 동의 설명 → Android Photo Picker(이미지 전용, 저장소 권한 요청 없음).
  - 취소 · 동의 거부 · 읽기 실패 · 생성 실패 · 시간 초과 · 취소는 모두 안내 문구와 함께 기본 모습으로 진행한다.
  - 사진 지우기를 누르면 참조와 유지 권한을 해제한다. 사진은 복사하거나 로그에 남기지 않고 URI 참조만 저장한다.
  - 이어하기 때 사진 접근이 만료됐으면 참조를 지우고 기본 모습으로 이어 간다.
- 외형 · 사진 참조 · 얼굴 시트 참조는 김우영 저장 모델 `AvatarConfig`에 그대로 저장한다.
- **캐릭터 조립** `PlayerAvatar`
  - 시기(6) × 체형(3, 김우영 `bodyTypeFor`) × 외형으로 그린다. 투명 배경이며 회색 임시 도형은 없앴다.
  - 정원률 레이어 PNG가 들어오면 우선 쓰고, 없으면 같은 규격의 도트 생성기로 그린다.
  - 사용 위치: 상단 · 자동 진행 무대(배경 장면 위에 캐릭터를 따로 얹음) · 장 표지 성장(지난 시기 → 이번 시기) · 홈 카드 · 미래 모습 · 기록증
- **Fake 생성 연결**: 얼굴 시트 · 미래 모습 요청은 `FakeGenerationClient`.
  - 이미지 30초 제한, 대기 중 취소 · 뒤로 가기 처리.
  - 디버그 빌드 홈에서 응답을 성공 · 지연 · 실패 · 시간 초과 · 취소로 바꿔 재현한다.
  - 화면에는 "예시 응답(서버 연결 전)"이라고 표시하고, 실제 AI 생성 성공처럼 보이지 않게 했다.

### 3. 종료 경험 · 기록 (F10-05, F10-06, F10-07, F10-08)

- 결말에 닿는 순간 완료 기록을 김우영 저장소에 저장한다(`saveCompletedLife`, runId upsert).
  - 주마등 도중 앱이 꺼져도 기록이 남는다. 다시 열거나 홈으로 가도 하나만 남는다.
- 종료 흐름: **주마등 → 미래 모습 → 인생기록증**
  - 주마등: 실제 선택 기록에서 고른 장면을 시간순 · 중복 없이 보여 준다(김우영 `recapMomentsFrom`). 장면 그림이 없으면 마지막 선택들을 그 시기 초상과 함께 보여 준다. 누르면 다음 장면, 건너뛰기 가능.
  - 미래 모습: 마지막 시기 · 체형 · 외형의 캐릭터를 가장 많이 걸어온 경로의 장면 위에 세운다. 노년기 전에 사망했으면 "마지막 모습"으로 쓴다. 실패 · 취소 · 시간 초과면 같은 기기 안 그림과 안내 문구를 보여 준다.
  - 인생기록증: 이름 · 칭호(당시 문구 스냅샷) · 결말 또는 실제 사망 시기 · 원인 · 교육 · 분야 · 직업 · 고용 · 가족 · 자녀 · 주거 · 경제력 · 업적 · 생애 요약 · 주요 선택. 미기록 사실은 "…기록 없음"으로 둔다.
- 홈
  - 현재 인생 카드(조립 캐릭터) · 이어하기 · 새 인생(덮어쓰기 확인)
  - **지난 인생 목록**: 저장소에서 읽어 재실행 후에도 남는다. 누르면 기록증부터 다시 열리고 주마등 다시 보기가 가능하다.
  - **칭호 수집**: 47개 중 받은 칭호를 먼저 보여 준다. 받은 인생 이름을 표시하고, 콘텐츠가 바뀌어도 받은 칭호는 당시 문구로 남는다.
- 결과 화면에서 앱을 껐다 켜면 같은 결과로 복귀한다.
  - 사건 머리를 되살리는 연결이 빠져 빈 화면이 나오던 문제를 고쳤다(`restoredDecisionUi`).
  - 결과는 다시 적용되지 않는다.

## 시연 순서

오프라인(비행기 모드)에서 진행한다. 서버 연결은 없다.

1. **홈**: 새 인생 살기 → 프로필.
   - 이름을 비워 두면 '플레이어'가 된다.
   - 성별 남, 기질 골똘한 아기를 고른다.
   - 모습에서 구릿빛 · 갈색 단발 · 큰 눈을 고르면 미리보기 세 시기가 바뀐다.
2. **사진(선택)**: 사진 고르기 → 동의하지 않음 → "동의하지 않아 기본 모습으로 진행합니다."
   - 다시 사진 고르기 → 동의 → 피커에서 취소 → 취소 안내.
   - 이 아기로 시작하기.
3. **영아기 「돌잡이」**: 상단 캐릭터 · 건강바, 하단 시기선, 가운데 사건, ABC 모서리 카드를 확인한다.
   - 장면 보기 → 그림만 남음 → 한 번 터치로 복귀.
4. **선택 후 결과 화면에서 앱을 강제 종료** → 다시 실행 → 이어하기 → 같은 결과 · 같은 능력치로 돌아온다(재적용 없음).
5. **유년기 장 표지**: 영아기 끝 → 유년기 시작 성장 그림. 「학원 고르기」에서 잠긴 선택지 이유를 확인한다.
6. 캐릭터를 눌러 **"지금까지의 나"**: 이번 시기 초점 · 인생 사실 · 능력치.
7. **"다음 결정까지"로 끝까지 진행** → 주마등(건너뛰기 가능) → 미래 모습 → 인생기록증 → 홈으로.
8. **홈 → 지난 인생**: 방금 인생을 눌러 기록증 → 주마등 다시 보기. 앱을 재실행해도 목록과 칭호가 남는다.
9. **칭호 수집**: 받은 칭호 수 / 47.
10. **(디버그 빌드) 홈의 개발용 생성 응답**: 지연 · 실패 · 시간 초과 · 취소를 고르고 지난 인생 → 기록증 → 주마등 다시 보기 → 미래 모습.
    - 로딩 · 취소 · 대체 문구를 확인한다.
    - 같은 방법으로 프로필 사진 얼굴 시트 생성도 확인한다.

- 같은 시기의 레이어는 모두 같은 캔버스 크기 · 같은 발 위치(맨 아래 행, 가로 가운데)로 그린 투명 PNG다. 그래서 좌표 없이 겹친다.
- 겹치는 순서: 몸 → 피부(얼굴 · 손) → 눈 → 머리.
- 네 장이 모두 있으면 PNG를 쓰고, 하나라도 없으면 도트 생성기로 그린다(`AvatarLayerAssets`). 다른 anchor 규격을 정하면 이 함수만 바꾸면 된다.

## 미완료 · 제한

1. **정원률 레이어 소재 미도착**
   - 지금 보이는 캐릭터는 같은 규격의 도트 생성기 그림이다. 회색 임시 도형은 아니다.
   - 6시기 × 3체형 × 외형이 실제로 구분되지만, 장면 그림만큼 정교하지 않다.
   - 소재가 오면 위 규격으로 교체된다.
2. **실제 AI 생성 미연결** (서버 · 공급자 미확정)
   - 얼굴 시트 · 미래 모습은 `FakeGenerationClient` 응답이다. 화면에도 "예시 응답(서버 연결 전)"으로 표시한다.
   - 사진 얼굴이 캐릭터 그림에 실제로 반영되지는 않는다.
3. **실기기 미확인**: 에뮬레이터(Pixel 6a API 35)와 Compose 테스트만 했다.
4. **주마등 체형**: 시기별 능력치 이력이 저장되지 않아, 지난 장면에도 마지막 체형을 쓴다.
   - 시기별 체형을 정확히 보이려면 저장 모델에 시기 말 능력치(또는 체형)를 남겨야 한다(김우영 협의 필요).
5. **사건 전용 그림이 거의 없음**
   - 장면 이미지가 지정된 사건은 5개뿐이다. 주마등은 전환점 · 큰 돌발을 함께 골라 플레이 중 보여 준 장면(경로 장면 → 빈 무대)과 같은 인물을 쓴다.
   - 정원률 신규 장면이 매핑되면 자동으로 그 그림이 나온다.
6. **시기선 이름**: 칸 너비가 고정이라 글꼴 1.3배까지만 커진다. 그 이상은 접근성 설명(현재 시기 · 몇 번째 해)으로 읽는다.
7. **"변경 전" 결말 화면**은 8주차 화면이다(이번 main의 결말 화면 = 8주차 요약 화면).
