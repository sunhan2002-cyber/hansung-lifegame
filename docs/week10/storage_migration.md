# 저장 포맷 v3 및 마이그레이션

## v3 추가 필드

- 현재 인생: `choices`, `pendingOutcome`, `avatar`, `awardedTitle`
- 완료 인생: 결말·칭호·최종 상태·선택 기록·아바타를 포함한 `CompletedLifeRecord[]`

## 복원 정책

1. `saveFormatVersion`이 1~3이면 읽는다.
2. v1/v2에 없는 새 필드는 빈 선택 기록, 결과 없음, 기본 아바타, 칭호 없음으로 채운다.
3. 과거 `life` 건강 필드는 `health`가 없을 때만 호환 읽기한다.
4. 잘못된 JSON, 필수 필드 누락, 지원 범위를 넘는 미래 버전은 예외를 UI로 전파하지 않고 `V4LoadResult.Invalid`로 안내한 뒤 현재 슬롯만 정리한다.
5. 읽는 중이던 `pendingOutcome`은 이미 적용된 전후 상태를 표시하므로 outcome RNG를 다시 실행하지 않는다.
6. 완료 기록은 `runId` 기준 upsert하여 중복을 막는다.

## 사용자 데이터 유지

- 새 인생 시작/현재 인생 삭제는 현재 저장 키만 제거한다.
- 완료 인생 목록은 별도 저장 키로 유지한다.
- 콘텐츠가 바뀌어도 과거 칭호 문구가 바뀌지 않도록 칭호 스냅샷을 저장한다.
