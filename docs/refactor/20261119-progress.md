### P1 콘텐츠와 저장

- `CachedContentLoader`가 원문·파싱 결과·실패 결과를 공유하고 읽기, 파싱, 검증 실패와 콘텐츠 지문을 구분한다. 필수 콘텐츠를 불러오지 못하면 새 인생 시작·이어하기에서 기존 저장을 덮어쓰지 않고 오류를 표시한다.
- `V4ProgressStore`와 `ProgressPersistence`에서 메모리 반영과 디스크 저장 완료를 구분했다. 디스크 확인은 UI 스레드 밖에서 실행하며 Pending·Durable·Failed 상태와 명시적인 재시도를 제공한다. 실패한 메모리 반영 작업도 같은 체크포인트로 재시도한다.
- 손상·미래 버전·문자열이 아닌 현재 저장과 완료 기록을 원래 형식으로 보존한다. 완료 기록과 현재 진행 슬롯은 한 편집으로 반영하며 runId별 기록 중복을 막는다. 읽을 수 없는 완료 기록에는 새 기록을 별도 보류 공간에 남긴다.
- 종료 버튼을 누른 뒤 Durable 상태가 되기까지 저장 대기 화면을 유지한다. 회전 시 대기 상태를 `rememberSaveable`로 보존하고 시스템 뒤로가기를 막는다. 프로세스 재생성으로 저장 상태가 Idle인 경우에는 디스크의 현재 슬롯 존재 여부로 완료된 저장과 복원할 체크포인트를 구분한다. 실제 Activity 재생성·느린 저장 fence·뒤로가기·홈 이동 1회 회귀가 수정 후 기기 실행에서 통과했다. 이는 실제 프로세스 강제 종료까지 같은 테스트에서 검증했다는 뜻은 아니다.
