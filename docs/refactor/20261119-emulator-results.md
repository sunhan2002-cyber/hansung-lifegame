## 성능과 설치 용량

Android 16/API 36 SwiftShader 에뮬레이터에서 네 화면을 각 모션 설정별로 콜드 실행했다. 각 화면에서 5초 대기 후 15초간 프레임과 메모리를 수집했다. 아래 지연은 Android `gfxinfo` 기준이며 표본은 조건별 1회다.

| 화면 | 효과 켬 지연 프레임 / 전체 | 효과 켬 95백분위 | 효과 끔 관측 프레임 |
| --- | ---: | ---: | ---: |
| 로비 | 222 / 222 | 150ms | 0 |
| 선생님의 오답 | 155 / 155 | 300ms | 2 |
| 서른의 첫 명함 | 147 / 147 | 300ms | 2 |
| 일요일 밤 11시 | 271 / 284 | 150ms | 2 |

효과를 켠 4개 화면의 PSS는 약 95~104MiB였다. 별도의 API 36 에뮬레이터에 Intel Iris Xe 그래픽 가속을 적용하자 같은 세 사건의 95백분위는 36~40ms, 첫 로비는 117ms였다. 이때 다른 에뮬레이터에서 전체 기능 회귀를 동시에 실행했다. 그래픽 가속 환경의 로비·주사위·장면 테스트 14개가 모두 통과했다. 휴대폰 GPU의 체감과 장시간 발열·배터리는 별도 실물 검증 항목이다.

같은 그래픽 가속 에뮬레이터에서 시스템이 안정된 후 로비 앱 프로세스를 종료하고 다시 측정했을 때는 895프레임 중 19개 지연(2.12%), 95백분위 40ms였다. 초기 측정과 편차가 있어 두 값을 함께 보존했다. 이 에뮬레이터에서 기존 주차별 화면·플레이 검증 61개를 추가로 통과했고 앱 서랍의 ‘인생게임’ 아이콘을 눌러 실제 앱이 열리는 것까지 확인했다.

기준 디버그 APK 230.39MiB에서 현재 디버그 APK 479.21MiB로 248.82MiB 증가했다. 현재 미서명 릴리스 APK는 474.95MiB이고, 세로 표시 이미지 디렉터리가 약 211.6MiB다. 원화를 보존하고 세로용 그림을 함께 제공한 비용이다. 릴리스 서명·배포 및 원격 CI는 별도로 남아 있다.
