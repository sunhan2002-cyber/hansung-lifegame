## 3. 결과가 갈리는 선택 33개

- 기본 결과(원래 문장·수치·플래그)는 그대로 두고 `chance` 와 `chanceWeights` 만 정했다. 갈래 결과는 새로 썼다.
- 일반 사건 선택지는 계속 잠그지 않는다. 능력치는 어느 결과가 나올 가능성이 큰지만 바꾼다 (FR-13). 화면에는 숫자 대신 가능성 문장이 나온다.
- 특수 사건(돌발)에는 갈래를 넣지 않았다. 후유증·사망 갈래는 보류 중인 항목이라 사인 문장만 붙였다.
- 기존 결과에 옛 보정값 `lifeDelta: 10` 이 붙어 있는 선택지는, 갈래 결과에도 같은 10을 `statDelta.건강` 에 합쳐 적었다. 새 `lifeDelta` 는 쓰지 않았다. 그래서 갈래 결과의 건강 값이 +8, +10 처럼 보이는데, 화면에 나오는 건강 변화는 기본 결과와 같은 기준이다.
- "가능성을 바꾸는 능력치" 열: ↑ 는 그 능력치가 높을수록, ↓ 는 낮을수록 그 결과가 잘 나온다는 뜻이다.

## 4. 사인 문장

- 엔진은 사망할 때 결과의 `deathCause` 를 먼저 쓰고, 없으면 "건강 악화"나 사건 제목을 쓴다 (`GameEngine.kt` 415행). 결말 화면은 "원인" 칸에 이 문장을 그대로 보여 준다.

## 5. 칭호 문구 (`titles.sample.json`)

결말(`endings.sample.json`)과 같은 조건 형식을 썼다. 엔진이 결말 판정 코드를 그대로 쓸 수 있다.

```json
{
  "titleId": "title_forever_leader",
  "text": "평생 반장",
  "description": "반장, 회장, 대표… 어디를 가도 맨 앞에 섰다.",
  "priority": 80,
  "conditions": {
    "minStats": {},
    "requiredFlags": [
      "class_leader",
      "leader_experience"
    ],
    "blockedFlags": []
  },
  "isDefault": false
}
```

## 6. 건강·운동능력 초점 분리

우영 님 밸런스 테스트는 시기마다 "목표 능력치가 가장 많이 오르는 초점"을 고른다. 건강 초점에 운동능력이, 운동 초점에 건강이 같이 들어 있어서 두 경로가 모든 시기에 같은 초점을 골랐다. 초점 수(시기별 5개)와 ID는 그대로 두고 수치만 바꿨다. 한 해 합계(+2)는 모두 유지했다.

| 시기 | 초점 | 전 | 후 |
| --- | --- | --- | --- |
| 유년기 | 운동 `focus_child_sports` | 운동능력 +2, 건강 +1, 사회성 -1 | 운동능력 +3, 사회성 -1 |
| 유년기 | 집안일 돕기 `focus_child_help` | 사회성 +1, 건강 +1, 경제력 +1, 행복 -1 | 건강 +2, 경제력 +1, 행복 -1 |
| 청소년기 | 운동 `focus_teen_fitness` | 운동능력 +2, 건강 +1, 지력 -1 | 운동능력 +3, 지력 -1 |
| 청년기 | 건강 `focus_young_adult_health` | 건강 +2, 운동능력 +1, 지력 -1 | 건강 +3, 지력 -1 |
| 청년기 | 도전 `focus_young_adult_adventure` | 운 +2, 행복 +1, 건강 -1 | 운 +2, 운동능력 +1, 건강 -1 |
| 중년기 | 건강 `focus_middle_health` | 건강 +2, 운동능력 +1, 행복 -1 | 건강 +3, 행복 -1 |
| 중년기 | 취미 `focus_middle_hobby` | 행복 +2, 운 +1, 경제력 -1 | 행복 +2, 운 +1, 운동능력 +1, 경제력 -2 |

그 결과 두 경로가 고르는 초점:

| 시기 | 건강 경로 | 운동능력 경로 |
| --- | --- | --- |
| 유년기 | 집안일 돕기 (생활 습관) | 운동 |
| 청소년기 | 마음 챙기기 | 운동 |
| 청년기 | 건강 | 도전 (배낭·산길) |
| 중년기 | 건강 | 취미 (자전거·등산 장비) |
| 노년기 | 초점 없음 (앱이 고르지 않음) | 초점 없음 |

다른 경로가 고르는 초점은 바뀌지 않았다 (사회성·경제력·행복·운 모두 같은 초점).
설명 문장도 수치에 맞게 고쳤다: 청년기 건강은 "잠과 식사, 검진", 중년기 건강은 "검진과 식단", 도전은 "배낭 하나로 낯선 도시와 산길", 취미는 "자전거, 등산화, 라켓", 집안일 돕기는 "생활 습관"을 넣었다.

엔진 쪽 필드 추가(`pathStat`)나 초점 6번째 추가 없이 해결했다. `image_routing.json` 에서 `focus_child_help` 의 이미지 주제가 `social` 인데, 이제 건강 쪽이라 `health` 로 바꾸는 것을 재겸 님께 제안한다 (이번 PR에서는 손대지 않음).

5. **이미지 주제 (재겸 님)**: `focus_child_help` 를 `social` → `health` 로 바꾸는 것 (6장 참고).
