## 유지한 요청 조건

차분한 빈티지 필름 톤, 도트풍, 40색 이하 느낌의 제한된 팔레트, 디더링 없음.
이미지 안의 제목·번호·글자·숫자·로고·워터마크·이모지·UI·필름 프레임을 요청하지 않았다.
3D/실사/웹툰풍·그라데이션·블러를 제외하고, 1인칭은 내 얼굴 대신 손과 시야로 표현하도록 요청했다.
평소 이미지의 아래 두 컷 폭이 넓게 나온 최초 결과는 최종 후보에서 제외하고, 동일한 격자 크기로 배치를 보완했다.

두 파일의 전체 해상도는 생성 도구가 반환한 모음 해상도다. 300×225는 **향후 개별 앱 자산의 규격**이며 모음 전체의 크기가 아니다.
장면별 색상 수·원본 규격 통과 판정이나 최종 스타일 승인으로 표시하지 않는다.
위 두 모음은 이전 생성 이력으로 보관한다. 현재 육안 검수 완료 보고는 독립 TXT로 새로 생성한 개별 예시 8장에 해당하며, 모음을 잘라내거나 모음의 최종 승인 상태를 변경한 것은 아니다.

과거 모음 생성·배치 수정 이력은 [prompts.json](prompts.json)에 보관한다. 이 JSON은 단일 장면 생성용이 아니다.
imageId/fileName 최종 매핑과 규격 검증은 김선한에게 인계한다. 현재 두 모음 파일명은 검토 파일명이며 게임 imageId 파일명을 대체하지 않는다.
이 절의 두 모음 이미지는 앱 코드·실제 사건 JSON·이미지 매핑에 연결하지 않았다. 개별 예시 8장의 debug 검수 연결과 구분한다. commit·push·PR 없음.

## 개별 생성용 프롬프트

2026-10-13: 모음용 원본 JSON은 유지하고, 장면별 생성용 TXT 8개를 따로 정리했다.
[장면별 프롬프트 목록과 사용법](../../week7_image_generation_prompts.md)을 참고한다.
각 TXT는 하나의 장면만 생성한다. 이후 개별 예시 8장을 생성하고 임시 검수 화면에 넣었으며, 2026-10-13 사용자 육안 검수 완료 보고를 반영했다. 앱용 300×225 축소는 보류하고 최종 파일명·매핑·규격 검증은 별도로 남긴다.

단일 장면 생성에는 위 안내의 TXT 하나만 복사한다. 각 TXT는 한 장면·한 시점·한 순간의 이미지 한 장을 지정하며, 다른 TXT나 참조 이미지와 합칠 필요가 없다.
