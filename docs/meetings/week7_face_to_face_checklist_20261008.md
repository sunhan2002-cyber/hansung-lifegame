## 5. Figma UI 시안 합의

7주차부터 앱 전체 UI를 김재겸 Figma 시안 기준으로 바꾼다.

- [ ] Figma 시안 전체 화면 같이 보기
- [ ] 현재 앱 화면과 Figma 화면 비교
- [ ] 필름 프레임 이미지 영역 적용 여부 확정
- [ ] 선택지 카드 UI 적용 여부 확정
- [ ] 돌발 사건 전용 색상/라벨 적용 여부 확정
- [ ] 결과 화면 구조 적용 여부 확정
- [ ] 기록/히스토리 패널 적용 범위 정하기
- [ ] 정확한 색상/간격은 Figma Inspect 가능할 때 보강하기로 합의

Figma 기준 핵심 구조:

- 상단: 나이, 성장 단계, 능력치 미니 표시
- 중앙: 필름 프레임 이미지
- 본문: 사건 제목, 사건 설명
- 하단: A/B/C 선택지 카드
- 결과: 선택 결과, 지표 변화 칩, 다음 진행 버튼
- 돌발 사건: 와인/붉은 계열로 일반 사건과 구분

  - [ ] 돌발 사건 화면

- [ ] 이미지 스타일 결정
