# 사건 이미지 공통 제작 가이드 — 정원률 담당 보조 작성

작성: 2026-11-03 · 기준 main `a9237d8` · 상태: **사용자 공통 화풍 확인 완료, 그룹·수량·팀 샘플 검토 대기**.

사용자는 두 수정본을 확인한 뒤 같은 도트 밀도·따뜻하고 차분한 색감·주인공 눈높이의 1인칭 구도를 나머지 사건에도 공통 기준으로 쓰는 데 동의했다.
이는 화풍 방향의 확인이며 전체 제작량·개별 그룹의 의미·실제 앱 크롭에 대한 팀 승인을 대신하지 않는다.
최신 기준은 [통합지시서](../통합지시서.md)다. 이 문서는 제작량·그룹·타 담당자 승인을 대신하지 않는다.

## 1. 장면을 결정하는 순서

1. 사건 ID와 **현재 제목·본문**을 읽는다. 그림 이름보다 본문이 우선한다.
2. 장소 → 현재 행동 → 반드시 보여야 하는 사물 → 인물/연령 → 시간대 → 시점을 기록한다.
3. 본문에서 명시되지 않은 장소·시간·소품은 `연출 제안` 또는 `본문 미지정`으로 표시한다.
4. 선택 전 시점을 그린다. 본문에 없는 승리·합격·결혼·사망·취업 등 결과를 넣지 않는다.
5. 기존 그림은 파일 존재, 원본 의미 적합성, 세로 크롭 적합성을 각각 검사한다.

예: `adult_020`은 노래방에 가자는 제안이지 노래방에서 노래하는 장면이 아니다.
`adult_072`는 명함이라는 제목보다 입사 제안서·시험 접수증 두 장이라는 본문이 중요하다.
`path_int_10`은 동네 도서관에서 사서와 대화하는 단계이므로 대학 강단의 강의 장면을 쓰지 않는다.

## 2. 시점·인물

- 사건의 지정 FIRST_PERSON을 보존한다. 미지정 사건의 본인 분류에서는 FIRST_PERSON을 제안했으며 확정 코드를 변경하지 않았다.
- 주인공 눈높이에서 손·발·주변 사물로 상황을 설명한다. 주인공의 얼굴, 거울 속 얼굴, 이름이나 얼굴이 나온 사원증은 넣지 않는다.
- 타인은 본문에 필요한 사람만 배치한다. 상대의 성별·직업·인원·가족 구성을 불필요하게 고정하지 않는다.
- 연령은 본문과 콘텐츠 시기를 함께 본다. `adult_072`의 MIDDLE 태그만 보고 50대로 그리지 않는다. 본문상 서른을 넘긴 인물이다.
- 같은 장소라도 초등/중등 급식, 신규 주택 대출/노년 빚 상환처럼 인물과 행동이 다르면 별도 완성 그림으로 취급한다.

## 3. 화풍과 실제 파일

- 기존 `images/week10/scenes`의 선명한 중간 밀도 도트풍, 차분한 갈색·종이색 계열, 제한된 색 단계와 명확한 물체 실루엣을 따른다.
- 그라데이션·디더링·사진 노이즈·3D·워터마크·과한 네온·흐린 글씨로 빈티지를 표현하지 않는다.
- 실제 파일은 **PNG, 양의 4:3 해상도**다. 현재 검증기의 `valid_dimensions`는 정확한 4:3 비율을 검사한다.
- 새 사건 장면은 현재 week10 장면과 같은 **300×225 px를 제안**한다. 이것은 검증기가 강제하는 유일 크기가 아니다. 기존 1448×1086 파일은 별도 합의 없이 일괄 축소하지 않는다.
- 원본 제작 파일과 앱 배포 파일을 구분한다. 저해상도 파일을 흐리게 확대해 고유 새 그림으로 세지 않는다.
- 일반 사건 장면은 불투명 전체 배경으로 만든다. 캐릭터 부품 PNG·얼굴 예제·결말 배경은 사건 완성 그림 수에서 제외한다.
- 앱 표시는 기존 최근접 보간 정책을 유지한다. 그림 안에 건강바·ABC·선택지·버튼·필름 프레임을 그리지 않는다.

## 4. 글자 없이 상황 전달하기

- 읽을 수 있는 이름·문장·금액·날짜·숫자·브랜드는 넣지 않는다. 정확한 대사와 수치는 게임 본문이 전달한다.
- 문서: 빈 칼럼, 무문자 표와 도형, 종이 묶음의 차이로 표현한다. 가짜로 읽히는 글자도 피한다.
- 휴대폰: 비문자 대화 블록·연락처 아이콘·수신 표시로 전달한다. 수신 문자와 현재 음성 통화는 다른 장면이다.
- 첫 월급은 입금 방향 단서, 동창회는 그룹 연락 단서, 새벽의 위로 요청은 야간 조명과 시험 준비 자료로 구별한다.
- 화면에 적힌 문장만 없애면 사건이 식별되지 않는 경우, 단순 휴대폰 공용 그림으로 승인하지 말고 `의미 검토 필요`로 남긴다. 그림이 본문 모든 문장을 문자 없이 재현한다고 주장하지 않는다.
- 타인 신분증은 사용자 사진이 아닌 비식별 가상 초상을 쓰며, 주인공 얼굴은 쓰지 않는다. 사용자 제공 얼굴 사진을 장면 제작 소재로 사용하지 않는다.

## 5. 전체화면 가운데 크롭

4:3 그림을 세로 화면에 가운데 잘라 채우면 좌우가 크게 사라진다. 가로 원본의 좌우 끝에 핵심 사물을 두지 않는다.

원본 크기 `W×H`, 실제 그림 표시 영역 `w×h`에서 배율은 `max(w/W,h/H)`다.
원본에서 보이는 가로 비율은 `(w/배율)/W`, 시작 x는 `(W-w/배율)/2`다.

| 전체 그림 표시 영역 예시 | 원본의 보이는 가로 폭 | 300px 원본의 대략적인 x 범위 |
| --- | ---: | --- |
| 360×640 | 42.19% | 86.7~213.3 |
| 360×740 | 36.49% | 95.3~204.7 |
| 360×800 | 33.75% | 99.4~200.6 |

위 수치는 기기 화면 전체와 실제 그림 표시 영역이 같다고 가정한 **구도 계산**이다. 실제 인셋·UI 영역은 에뮬레이터에서 측정해야 한다.

- 첫 제안은 **원본 x=34~66%의 중앙 세로 영역** 안에 핵심 행동과 필수 사물이 함께 남게 구성한다. 단순히 물체 중심점만 넣고 형태를 바깥에 두지 않는다.
- 두 서류·급식판과 옮기는 브로콜리·줄넘기와 발 등 의미를 만드는 조합 전체를 확인한다.
- 중심에 담을 수 없으면 원본을 늘이거나 장면을 다른 사건으로 바꾸지 말고 구도를 다시 만든다. 세로 원본 규격 도입은 프론트·QA와 별도 합의한다.
- 접촉시트 원본 검수와 실제 화면 검수를 별도로 기록한다. 장면 보기, 일반 UI, 큰 글꼴, 결과 후 복원에서도 확인한다.

## 6. 재사용 판정

재사용에는 장소·행동·필수 사물·연령·시간·시점이 모두 충돌하지 않는 근거가 필요하다.
태그나 배경만 같다는 이유로 완성 그림을 공유하지 않는다. 배경 레이어를 재활용하는 것과 동일 사건 그룹으로 묶는 것은 다르다.

본인 70행의 그룹은 아직 70개의 **후보**다. 예를 들어 아래 쌍은 현재 분리 제안이다.

## 7. 수량 확정 뒤 샘플과 전원 제작

승인 그룹과 담당자 배정이 나오면 대표 샘플 3장을 만든다. 현재는 다음 **유형**을 후보로 제안하며 그룹 배정·샘플 승인은 아직 없다.

1. `path_hea_01` 유형: 인물 손과 급식판·브로콜리의 중앙 크롭 검증.
2. `adult_015` 유형: 글자 없이 휴대폰 사건을 설명하는 방식 검증.
3. `path_int_10` 유형: 노년 눈높이·사서·도서관 게시 공간 검증.

샘플을 의미 담당·프론트가 승인한 뒤 같은 규격/프롬프트를 전원에게 제공한다. 이미 승인 그룹의 PNG라면 총량 M에 한 번만 센다.

프롬프트 작성은 그림 제작 완료가 아니다. 생성 후 원본과 크롭을 직접 검수하고 실제 PNG를 제출한다.

## 8. 파일·manifest·검수 상태

- 승인 전 `grp_wr_<eventId>`는 제안 그룹 ID이며 앱의 imageId를 바꾸지 않는다.
- 승인 뒤 경로 후보는 `images/followup_20261031/<approvedGroupId>.png`다. 파일명·imageId는 김선한 통합 및 김재겸 연결과 맞춘 뒤 확정한다.
- 개인 manifest에는 승인 그룹 ID, 사용 사건 ID 목록, 상대 경로, 실제 픽셀 크기, SHA-256, 생성/편집 방법·프롬프트, 자체 검수, 의미/크롭 검토 상태를 적는다.
- 중앙 `image_ids.sample.json`과 `image_routing.json`을 각자 덮어쓰지 않는다.
- 상태를 `분류 제안 → 교차 검토 → 그룹/수량 확정 → 샘플 승인 → PNG 제작 → 앱 연결 → 전수 QA`로 구분한다.
- 전수 시각 검수는 사건 ID·본문 요약·선택 그룹·실제 이미지가 함께 보이는 자료에서 수행한다. 누락 파일을 공용 배경으로 표시한 화면을 사건 대응 완료로 세지 않는다.

이 가이드와 분류표는 현재 단계의 제출물이다. N/R/M, 대표 샘플 승인, 전원 새 PNG, 최종 앱 전수 검수는 아직 완료로 표시하지 않았다.
