## 실제 수정과 추가 발견

PR #49 댓글의 12건 대신 실제 의미 CSV의 **13건**을 모두 반영했다. 친구 모임을 동료로 적은 부분,
축사 부탁 전에 마이크·하객석을 제안한 부분을 고쳤고 장소는 최신 PR #51 제작 명세와 통일했다.
개인 CSV의 승인·제작 칸은 초기 분류 양식 보존이며 실제 담당·제작 상태는 **최신 PR #51 제작대장**을 따른다.

몸살은 휴대폰·물컵·체온계, 출입문은 사원증·빨간 표시·닫힌 게이트를 중앙에 모았다.
보건실은 글자 흔적을 없애고 물컵을 중앙에, 자판기는 원래 두 캔인 수를 유지하면서 같은 콜라 색으로 맞췄다.
예전 debug 사본이 최신 main 그림을 덮어쓰는 문제도 고쳐 실제 APK와 앱 파일이 일치하도록 했다.
해당 오류를 감지하는 검사와 재현/복구 확인을 추가했다.

새 공통 샘플은 급식 브로콜리와 첫 월급이다. 기존 도서관과 함께 3종 검토 대상이다.
샘플은 지정 경로의 실제 PNG와 미리보기를 제공하며 아직 최종 사건 라우팅은 변경하지 않았다.
모두 내장 image_gen 생성/편집 PNG 1448×1086 원본이며 외부 이미지 fetch나 코드 이미지 편집을 하지 않았다.
