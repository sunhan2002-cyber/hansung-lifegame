## 시각 판단

- 두 실제 배경 위에서 노랑은 황금색, 주황은 붉은 주황으로 구분된다. 기존 색 유지 제안이다.
- 불투명 단색의 두꺼운 채움 덕분에 배경 무늬가 채움 안으로 비치지 않는다. 트랙만 반투명이다.
- 색만으로 모든 사용자·모든 배경에서 구분된다고 주장하지 않는다. 기존 상태 설명 `건강 주의/위험/위급`과 접근성 진행 정보를 유지한다.
- 순백색 위 명도 대비는 노랑 약 2.01:1, 주황 약 2.82:1, 두 색 서로 약 1.40:1이다(sRGB 상대 명도 계산). 이 값은 배경 그림 전체의 대비 측정이나 접근성 적합 판정이 아니다.
- 실제 최종 그림 배정 뒤 밝은 노란 물체가 건강바 뒤에 오는 경우를 추가 확인한다. 문제가 생기면 무조건 다른 색으로 바꾸기보다 트랙/중립 외곽선으로 분리하는 방안을 김재겸과 검토한다. 이번에는 UI 코드를 임의 변경하지 않았다.
