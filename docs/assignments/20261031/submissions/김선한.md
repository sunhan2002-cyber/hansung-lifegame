## 제작 의사결정

`adult_015`·`adult_080`의 같은 급여 알림 구도만 한 그룹으로 묶었다. 은행 등 다른 공유 제안은 별도 그룹으로 유지했다. FIX 53건·REPLACE 5건은 장소·현재 행동·인물·사물·시간을 수정한 착수 명세에 반영했다.

40건의 이전 미해결 기록은 [조치 목록](김선한_교차검토_미해결.json)에 제작 구도·담당자·상태를 추가했다. 이는 PNG 자체의 수정 완료를 뜻하지 않는다. 기훈의 141건 추가 검토는 이제 회수됐으며 더 이상 대기 조건이 아니다.

`path_luk_09` 취출구 캔은 원본도 2개다. 1차의 ‘3개’ 판정을 철회하고 두 캔이 콜라로 읽히는 색 보정으로 조정했다. 진열 칸까지 세어 잘못 판단했던 부분을 정정한다.

이미지 검사기는 분류 구조와 최종 PNG 인수를 분리한다. 승인 manifest에는 현재 main에서 확인되는 재사용 원본 3개만 등록했고, 미납품·미연결 항목의 최종 인수 실패를 유지한다. 최종 실패는 제작 착수 금지 조건이 아니다.
