# 재사용 묶음·판정 차이 검토 — 2026-11-03

정원률 담당 보조 검토(Codex). 근거는 공용 분류대장의 현재 본문, 원본 PNG 직접 확인,
김재겸 PR #47과 신기훈 PR #49의 읽기 전용 분류/의미 검토다.
팀원에게 메시지를 보내거나 타인의 승인 칸을 대신 작성하지 않았다.

## 3. 기존 그림 판정의 합의 필요 사항

| 사건 | 김재겸/김우영 제안 | 신기훈 의미 검토 | 이번 시각 검토 |
| --- | --- | --- | --- |
| `path_fit_09` | 기존 그림 재사용 후보 | REPLACE | **교체 필요**. 시니어 접수처 본문과 젊은 출발선 그림이 어긋남. |
| `path_hea_10` | 기존 그림 재사용 후보 | REPLACE(시계·동료 수정 요청) | **수정 필요**. 21시와 남은 동료를 반영하기 전 R에 넣지 않음. |
| `teen_042` | 기존 그림 재사용 후보 | REPLACE(시험지·넘기는 손 수정 요청) | **수정 필요**. 빈 시험지·판서 중 교사·앞자리 행동을 고치기 전 R에 넣지 않음. |

`REVISE_REQUIRED`와 `REPLACE_REQUIRED`는 현재 파일을 그대로 쓸 수 없다는 점에서 같다.
팀의 N/R/M 집계에서는 둘 다 **R 제외, 수정/교체 제작 M 후보**로 다뤄야 한다.
수정은 새 파일 한 장으로 납품될 수 있으므로 기존 원본과 수정본을 중복 가산하지 않는다.

## 4. 남은 확정 순서

1. 김선한의 71행과 이번 정원률 70행을 기존 세 명의 분류와 합본한다.
2. 신기훈이 미검토 본문 및 묶음의 의미를 확인한다.
3. 정원률 담당 시각 검토와 의미 검토가 충돌하는 행을 해결한다.
4. 김선한이 승인 그룹, 재사용 가능한 실제 파일, 수정/신규 구분 및 N/R/M을 확정한다.
5. 담당 배정 뒤 대표 샘플 3장을 제작하고 의미·실제 크롭 승인을 받는다.

이 문서는 확정표나 승인 기록이 아니다. 현재 대량 제작은 시작하지 않았다.
