# 정원률 — UI·이미지

먼저 [통합지시서](통합지시서.md)를 읽는다. 이번 담당 유형은 **1번 색상·가독성 검수 + 3번 분류·공통 이미지 규격·본인 제작·전수 시각 검수**다.

## 즉시 시작

1. 본인 70행(파일 누락 67·기존 파일 3)을 분류한다. 파일이 있는 그림도 본문에 맞는지 직접 본다.
2. 건강 4색의 초록·노랑·주황·빨강을 김재겸과 맞추고, 밝거나 어두운 사건 배경에서 노랑과 주황이 구분되는지 실제 화면으로 확인한다.
3. 기존 도트풍, 장소·인물 연령·필수 사물·시점, 4:3 실제 파일 규격, 전체화면 가운데 크롭 안전 영역, 파일명·경로를 공통 가이드로 정리한다.
4. 신기훈과 함께 재사용 그룹을 검토한다. 의미가 다른 장면을 공용 이미지로 묶어 제작 수를 줄이지 않는다.

## 수량 확정 후

- 승인 그룹 중 대표 샘플 3장을 먼저 제작한다. 샘플이 승인 그룹에 속하면 M에서 한 번만 세며 다른 사람 배정분과 중복 제작하지 않는다.
- 샘플의 본문 적합성·실제 앱 크롭을 확인한 뒤 전원에게 프롬프트/규격을 공유한다. 샘플 승인 전에 대량 생산시키지 않는다.
- 본인에게 배정된 전체 이미지를 제작한다. 타 4명의 이미지는 가이드·시각 검수로 지원하되 제작을 혼자 떠맡지 않는다.
- 전체 접촉시트를 검수하고 핵심 사물 누락·잘림·화풍 불일치·UI 글자 포함·다른 사건 묘사를 반려한다. 수정된 파일을 다시 검사한다.

## 제출과 완료

`submissions/정원률.md`: 본인 분류, 공통 가이드·샘플 승인, 본인 PNG·그룹 ID·manifest, 전수 시각 검수 결과·실제 앱 캡처.
아바타 부품·결말 배경·프롬프트 수를 사건별 완성 이미지 수로 합산하지 않는다. 과거의 ‘신규 24장 이상’은 이번 전수 대응 완료 기준을 대신하지 못한다.
