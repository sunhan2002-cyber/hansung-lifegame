# 김선한 — DB·QA·통합

먼저 [통합지시서](통합지시서.md)를 읽는다. 이번 담당 유형은 **1·2번 QA/통합 + 3번 분류·수량 확정·본인 이미지 제작·전수 인수**다.

## 즉시 시작

1. `사건이미지_분류대장.csv`의 본인 71행을 읽고 분류한다. 이 중 67건은 우선 이미지 파일이 없고 4건은 실제 파일의 의미를 재검토한다.
2. 나머지 4명의 분류 행을 회수하되 빈 행·중복 사건·분류 불일치를 확인한다. 파일 존재나 스탯 태그를 의미 검수로 대체하지 않는다.
3. 건강 4색의 전체 경계표, 타이핑 중 터치 시 전문 표시·콜백 0회·다음 사건·복원 시나리오를 검증 항목으로 고정한다. 김재겸의 코드 변경 전후 검사를 구분한다.
4. 이미지 전용 검증을 보강한다. 우선 이미지 파일 누락과 공용 대체 비율을 별도로 보고하고, 기존 missing 허용 검사로 완료를 선언하지 않는다.

## 분류 합본 후

- 신기훈 의미 검토·정원률 시각 검토를 통과한 그룹으로 N/R/M을 계산해 `제작수량_확정표.md`와 `이미지그룹_제작대장.csv`를 만든다. 사건 수와 고유 그룹 수를 혼동하지 않는다.
- 확정 M을 5명에게 균등 분배하고 그룹별 유일 제작자·난이도·PR 범위를 기록한다. 본인도 배정받은 이미지를 실제 제작한다. 총괄 역할을 이유로 제작에서 제외되지 않는다.
- 각 팀원의 manifest/PNG를 통합하고 모든 사건→승인 그룹→실제 PNG 연결을 검사한다. 이미지 그룹·시나리오 의미의 최종 근거를 회수한다.

## 제출과 완료

`submissions/김선한.md`: 개인 분류, N/R/M 산출 근거, 5명 제작 배정표, 본인 PNG/그룹 ID, 전수 커버리지, 실행 명령·결과·최종 커밋·APK/해시·알려진 제한.
건강 4색·타이핑 건너뛰기·352개 기준 사건 전수 이미지 대응을 각각 검사한다. 콘텐츠가 늘면 분모를 갱신한다. 미완료는 미완료로 표시한다.
