# 신기훈 — 시나리오

먼저 [통합지시서](통합지시서.md)를 읽는다. 이번 담당 유형은 **2번 실제 문장 검증 지원 + 3번 전수 의미 분류·그룹 검토·본인 이미지 제작**이다.

## 즉시 시작

1. 본인 70행(파일 누락 67·기존 파일 3)의 제목뿐 아니라 본문 전체를 읽고 핵심 행동·사물·장소·시기·인물·시점을 기록한다.
2. 타이핑 검사용 실제 긴 문장·줄바꿈·대사·이모지 사례와 사건 ID를 김재겸/김선한에게 제공한다. 본문을 짧게 고쳐 건너뛰기 요구를 회피하지 않는다.
3. 5명 분류 합본을 전수 검토한다. 장소가 같아도 사건 핵심 행동이 다르면 그룹을 나누고, 재사용한다면 이유를 남긴다. 스탯 분류를 장면 의미 분류로 바꾸어 부르지 않는다.
4. 선택 전 장면에 특정 선택 결과·실패·사망이 확정되어 보이지 않는지 확인한다. 예: 브로콜리 급식과 체온계가 놓인 감기 방은 별도 장면이다.
5. 분류상 충돌은 정원률과 해결하고 김선한에게 승인/미해결 목록을 넘긴다. 시나리오 의미를 이미지와 맞추려고 임의로 바꾸지 않는다.

## 수량 확정 후

- 본인 배정 그룹을 실제 PNG로 제작한다. 역할이 시나리오라는 이유로 이미지 제작을 생략하지 않는다.
- 전수 사건·이미지 접촉시트를 검토해 행동·사물·시점 불일치를 표시하고 수정 후 재확인한다. 대표 몇 장만 보고 전체 승인하지 않는다.

## 제출과 완료

`submissions/신기훈.md`: 본인 분류, 전수 그룹 의미 판단 근거·재사용 이유, 타이핑 사례 ID, 본인 PNG·그룹 ID·manifest, 최종 의미 검수 기록.
이번 과제에 필요하지 않은 신규 사건 대량 추가로 이미지 대상 수를 흔들지 않는다.
