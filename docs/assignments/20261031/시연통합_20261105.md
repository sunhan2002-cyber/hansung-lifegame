통합 과정에서 adult_002의 미지정 종목을 축구로 단정하는 소품을 제거하고, adult_080의 실제 화면이 승인된 첫 월급 그림을 선택하도록 연결했다. 검토 근거와 해시는 `submissions/통합_그림검토_20261105.json` 및 승인 manifest에 기록했다. Codex 자체 검토는 팀원 독립 서명으로 표시하지 않았다.

## 시연 순서

1. 새 게임을 시작하고 사건 화면까지 진행한다.
2. 시나리오 타이핑 도중 터치하여 전문이 즉시 표시되는지 확인한다.
3. 장면 보기를 눌러 UI가 숨겨지고 배경이 화면을 채우는지, 다시 터치하면 선택지가 돌아오는지 확인한다.
4. 선택 후 결과·스탯 변화와 다음 사건 진행을 확인한다. 건강 색상은 60~100 초록, 30~59 노랑, 11~29 주황, 0~10 빨강이다.
5. 진로·가족 등 사실 변화가 생기는 선택을 진행하고 인생 요약에서 결과를 확인한다.

특정 파일럿 사건은 일반 플레이에서 항상 등장하지 않는다. 사건별 연결은 `SceneCropReviewTest`의 실제 콘텐츠 기반 화면 검사로 재현할 수 있다.

## 검증과 남은 범위

- 기준 통합본: debug 단위 테스트 178개, release 178개, Python 26개, Android 55개 통과. 사건 24개 화면의 실제 이미지 연결과 크롭 검사 완료. 상세 증거는 `submissions/통합검증_20261105.json`에 보관했다.
- 최종 시연 빌드의 재검증 결과는 `submissions/시연최종검증_20261105.json`을 기준으로 한다.
- 시연 승인 범위: 제출 그림 12그룹 + 기존 재사용 3그룹 = 15그룹, 16사건. 다른 사건은 기존 이미지/대체 경로를 사용하며, 사건별 의미 일치가 모두 완료된 상태는 아니다.
- 제작대장의 미완료 336그룹 중 추가 생성한 9장은 `submissions/pending_images_20261105/`에 보관했다. 이들은 검토 대기이며 APK에 포함하지 않았다. 따라서 새로 생성할 물량은 327그룹이고, 9그룹의 검토·수정·연결이 별도로 남는다.
- 보관본 중 adult_016은 자리·문 위치와 세로 크롭의 의미 일치 검토가 남았다. 미완료 이미지를 승인으로 처리하거나 최종 전수 인수 게이트를 완화하지 않았다.
