# 팀원별 AI 작업 프롬프트

아래 **공통 문구와 본인 문구**를 함께 AI에게 전달한다. 저장소 최신 main과 지정 문서를 실제로 읽게 한다.

## 공통

```text
인생게임 후속 수정 과제를 수행해 줘.
먼저 로컬 변경을 확인해 보존하고, 최신 원격 main과 현재 작업 브랜치를 비교해.
docs/assignments/20261031/통합지시서.md, 내 개인과제 파일,
docs/assignments/20261031/현황.json과 사건이미지_분류대장.csv를 읽어.
이번 요구는 ① 건강 게이지 4색 ② 타이핑 중 터치하면 즉시 전문 표시
③ 모든 사건의 의미에 맞는 이미지 전수 분류→총량 확정→5명 제작→앱 연결이야.
건강 경계는 60~100 초록, 30~59 노랑, 11~29 주황, 0~10 빨강으로 문서에 고정돼 있어.
새 건강/생존 규칙을 만들지 말고 색 표시만 바꿔.
타이핑 완성 터치로 선택/장면 진입/다음 사건/보상이 동시에 실행되면 안 돼.
현재 352사건 중 우선 이미지 파일 보유 17건, 누락 335건이지만 이것을 확정 제작 장수로 부르지 마.
본인 분류 대상 행의 본문과 실제 파일을 직접 보고 기록해. 스탯 태그만으로 그룹을 묶지 마.
분류 합본의 N/R/M과 제작 그룹이 확정되기 전에는 임의로 장수를 정하거나 대량 제작하지 마.
확정 뒤에는 본인에게 배정된 이미지도 직접 제작하고 실제 PNG와 개인 manifest를 제출해.
중앙 JSON을 다른 팀원과 동시에 덮어쓰지 말고, 코드 소유자와 합의한 범위로 PR을 나눠.
장면 전체화면 수정 3736cc9는 조사 당시 main에 없었으니 포함 여부를 확인하고 보존해.
과거 문서의 해 단위 진행 설명이나 실제 서버가 없는 Fake를 구현 완료 사실로 복사하지 마.
검사를 끄지 말고 미완료·미실행·미해결을 구분해 보고해.
실행 증거와 변경 파일, 본인 그룹/PNG 수, 의존 항목을
docs/assignments/20261031/submissions/내이름.md에 남기고 개인 브랜치의 PR로 제출해.
main에 직접 푸시하지 마.
```
