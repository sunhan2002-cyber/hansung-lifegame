# 김재겸 — 프론트엔드

먼저 [통합지시서](통합지시서.md)를 읽는다. 이번 담당 유형은 **1번 건강 4색 구현 + 2번 타이핑 터치 구현 + 3번 분류·본인 이미지 제작·앱 연결**이다.

## 즉시 시작

1. 분류대장 본인 70행(우선 파일 누락 67·기존 파일 3)을 검토한다.
2. `PlayChrome.kt`의 건강 3단계를 4단계로 변경한다. 60~100 초록, 30~59 노랑, 11~29 주황, 0~10 빨강. 게이지 두께·배치·숫자 숨김을 유지하고 접근성 단계도 맞춘다.
3. `DecisionScreen.kt`에서 본문 출력 중 터치하면 현재 본문을 즉시 완성한다. 기존 타이핑 작업이 다시 문자 수를 줄이지 않도록 종료/취소하고 동일 터치로 버튼이나 선택이 실행되지 않게 한다.
4. 전체화면 장면 보기 수정 `3736cc9`가 main에 없으면 수정 내용을 포함한다. 위아래 여백 제거, 블러 제거, UI 숨김, 한 번 터치 복귀를 보존한다.
5. 건강 경계와 타이핑 건너뛰기 Android 검사 및 실제 화면을 제출한다. 터치 시점·빠른 연타·다음 사건·동작 줄이기·복원·돌발 팝업을 확인한다.

## 수량 확정 후

- 본인 제작 그룹의 실제 PNG를 만든다. 이미지 제작을 정원률에게 전부 넘기지 않는다.
- 개인별 manifest를 기준으로 실제 우선 이미지와 파일 경로를 연결한다. 중앙 JSON은 합본 담당과 순서대로 편집한다.
- 세로 화면 중앙 크롭에서 핵심 사물이 잘리지 않는지 정원률과 검수하고, 무관한 공용 그림을 성공 화면으로 대신 보여주지 않는다.

실제 앱 캡처를 제출하며 앱 화면을 생성 이미지로 대신하지 않는다.
