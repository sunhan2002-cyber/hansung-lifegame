# 김우영 — 게임 로직

먼저 [통합지시서](통합지시서.md)를 읽는다. 이번 담당 유형은 **1·2번 상태·게임 로직 검증 + 3번 분류·본인 이미지 제작·복원 계약**이다.

## 즉시 시작

1. 분류대장의 본인 71행을 직접 검토한다. 파일 없는 67건과 파일 있는 4건 모두 의미 분류 대상이다.
2. 건강 색 구간은 표시 규칙이며 생존 규칙 변경이 아님을 확인한다. 10이 빨강이 된다는 이유로 조기 사망시키거나 스탯을 깎지 않는다. 기존 건강·저장 계약은 유지한다.
3. 타이핑 완료 터치와 선택/진행을 분리하는 상태 계약을 김재겸과 맞춘다. 전문 표시만으로 엔진 진행, 사건 이동, 결과 적용, 보상이 발생하지 않는지 재현한다.
4. 사건 이미지의 우선순위(`povImageId`→`imageId`), 결과·이어하기·완료 기록에서 사용할 이미지 식별자 계약을 문서화하고 실제 동작과 대조한다. UI 경로 선택 로직을 별도로 중복 구현하지 않는다.

## 수량 확정 후

- 본인 배정 그룹을 정원률 가이드에 맞춰 실제 PNG로 제작하고 개인 manifest를 제출한다. 사전 67개는 누락 사건 조사 수이며 확정 제작 장수가 아니다.
- 그림을 새로 매핑한 뒤 저장된 사건 ID가 다른 사건 이미지로 복원되지 않는지 검사한다. 판정 시점·선택 결과를 바꾸어 그림 문제를 감추지 않는다.
