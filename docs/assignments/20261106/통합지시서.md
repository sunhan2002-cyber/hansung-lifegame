# 11주차 통합지시서 — 용어·사진·서사·선택지·컷신·이미지 전수 마무리

작성일: 2026-11-06

대상: 김선한·김우영·김재겸·신기훈·정원률

이번 과제는 최신 사용자 요구 9개를 실제 앱에 반영하고, 지난주부터 남아 있는 사건 이미지 제작·검수·연결을 함께 마무리하는 과제다. 기능을 구현했다고 말하려면 실제 코드, 실제 PNG/리소스, 실행 검사, 미완료 목록을 모두 제출해야 한다.

## 절대 기준

- 최신 `main`에서 작업 브랜치를 만든다. `main`에 직접 푸시하지 않는다.
- 기존 건강 스탯·생존 판정·저장 계약을 임의로 바꾸지 않는다.
- 실제 사용자 사진은 동의와 권한을 거친 뒤 기기에서 선택·처리한다. 저장소에 사용자의 개인 사진을 커밋하지 않는다.
- 이미지가 파일로 존재하는 것과 사건 의미가 검수되어 앱 경로에 연결된 것은 별도 상태다.
- 지난주 이미지 게이트의 현재 수치는 `scripts/validate_followup_image_coverage.py` 결과를 기준으로 한다. 최신 기준 승인 15그룹·16사건, 승인 대기 336사건이다. 새로 추가된 이미지도 의미 검수·실기기 크롭·라우팅 전에는 완료로 세지 않는다.
- 4:3 원본 PNG, 도트풍, 1인칭 구도, 중앙 안전영역, 글자·UI를 이미지에 굽지 않는 기준을 유지한다.
- 실제 구현·검증이 끝나지 않은 항목은 `PENDING`으로 남기고 완료라고 쓰지 않는다.

## 사용자 요구 9개와 완료 기준

### 1. 용어와 시작 흐름 정리

`기질`, `우렁찬 아기`, `엉뚱한 아기`처럼 어색한 표현을 사용자가 이해할 수 있는 `성향`, `활발한 편`, `파고드는 편`, `엉뚱한 편` 등으로 통일한다. 시작 화면은 주사위로 초기 능력치를 랜덤 결정하고, 최대 3회 다시 굴린 뒤 자동으로 가까운 성향을 보여준다. 기존 `starter_*` 플래그와 선택지 조건은 보존한다. 화면 문자열·접근성 문자열·테스트 기대값을 함께 바꾼다.

### 2. 실제 사진 기반 캐릭터

사진 선택→권한·동의→로컬 처리→시기별 얼굴 합성→현재 모습과 인생 요약 표시의 실제 흐름을 완성한다. 네트워크나 API 키가 없는 경우에도 기본 도트 캐릭터로 안전하게 돌아가야 한다. 사진 미선택·권한 거절·잘못된 파일·프로세스 복원도 검증한다. 개인 사진 자체를 저장소에 넣지 않는다.

### 3. 글씨 크기

작은 본문·대사·선택지 설명·결과 문구를 실제 에뮬레이터에서 읽을 수 있도록 단계적으로 키운다. 화면이 잘리지 않도록 줄바꿈·스크롤·버튼 높이를 함께 조정하고, 기존 장면 보기·선택지 터치 영역을 유지한다. 핵심 화면 캡처를 제출한다.

### 4. 자동 스토리 흐름과 최신 기록

선택지 결과 외에도 자동 진행 중 시기와 상황에 맞는 일상 이야기 후보를 보여준다. 자동 문장이 결혼·취업·합격을 사실처럼 단정하지 않게 한다. 기록 목록은 가장 최근 항목이 위에 오며, 선택 결과와 자동 이야기를 구분한다. 저장·복원 후 순서와 중복을 검사한다.

### 5. 나이에 따른 얼굴 개선

머리카락만 바뀌는 현재 외형을 보완한다. 영아·유년·청소년·청년·중년·노년의 얼굴 영역이 분명히 보이고, 중년·노년은 주름·흰머리·눈 형태가 자연스럽게 달라져야 한다. 도트 캐릭터와 선택적 실제 사진 얼굴이 서로 깨지지 않아야 한다. 실제 화면 캡처와 리소스 목록을 제출한다.

### 6. 시작 돌잡이 컷신

고정 돌잡이 결과를 바로 확정하지 않고, 짧은 컷신/연속 장면으로 보여준 뒤 사용자가 시작 상황을 이해하도록 한다. 동영상 파일을 무조건 넣지 말고, 우선 Compose 애니메이션 또는 순차 컷 PNG로 오프라인 동작을 구현한다. 컷신 건너뛰기·접근성·재시작·저장 복원에서 중복 보상이 발생하지 않아야 한다. 컷신의 애니메이션과 실제 스탯 반영을 분리한다.

### 7. 선택지 중심 시각 설계

선택지 카드에서 사회성·행복 같은 보조 태그는 기본 노출을 줄이거나 접을 수 있게 한다. 건강 회복의 초록색만 눈에 띄는 구조를 제거하고, 선택지 제목·행동·결과를 우선 강조한다. 선택지 카드의 hover/pressed/선택 완료 상태와 접근성 설명을 추가한다. 스탯 변화는 보조 정보로 유지하되 선택지 본문보다 강하지 않게 한다.

### 8. 사건 이미지 선노출

시나리오 제목·본문이 나타난 뒤 해당 사건 이미지를 먼저 보여주고, 짧은 표시 시간 또는 사용자의 한 번 터치 후 선택지 화면으로 넘어간다. 기존 장면 보기 버튼은 중복 동작이 되지 않게 정리한다. 본문 타이핑 중 터치 시 전문 표시 규칙, 장면 전체화면, 한 번 터치 복귀, 선택지 한 번만 반영 규칙을 보존한다. 이미지가 없는 사건은 검수된 안전 대체 화면을 쓰되 미완료로 기록한다.

### 9. 선택 결과 애니메이션

선택 직후 `건강 +3`, `지력 -2` 같은 변화 문구를 고정 텍스트로 오래 남기지 말고, 카드 위에 짧게 나타났다 사라지는 애니메이션으로 바꾼다. 양수·음수·복수 스탯·건강 0 사망·빠른 연속 입력·복원에서 결과가 한 번만 적용되어야 한다. 애니메이션이 꺼진 환경에서는 즉시 읽을 수 있는 정적 대체를 제공한다.

## 이미지 미완료 트랙

지난주 이미지 작업은 “PNG가 제출됨”과 “앱에서 승인됨”을 분리한다. 현재 승인 manifest는 15그룹·16사건이며, coverage 검사상 336사건이 승인 대기다. 5명은 `이미지그룹_제작대장.csv`, `이미지제작_착수명세.json`, 최신 개인 manifest를 읽고 본인 `productionOwner` 행부터 진행한다.

각 이미지 제출에는 실제 PNG, 그룹 ID와 사건 ID, 원본 크기·SHA-256, 프롬프트/제작 방법, 본문 의미 검수, 4:3·중앙 크롭 검수, 앱 경로 연결 상태가 필요하다. 미완료 그룹을 다른 그룹 그림으로 대체하거나 숫자만 늘려 완료 처리하지 않는다.
