## 1. 용어 검토

### 1-1. 성향 이름과 사건 본문

`characters.sample.json`의 성향 이름(활발한 편·파고드는 편·엉뚱한 편)은 `starter_*` 플래그로만 사건과 연결된다. 사건 본문은 성향 이름을 직접 부르지 않으므로 이름을 바꿔도 본문 수정은 필요 없다. 플래그로 열리는 사건 12개의 본문이 새 이름의 뜻과 맞는지 봤다.

| 성향 (플래그) | 사건 | 판정 |
| --- | --- | --- |
| 활발한 편 (`starter_loud`) | `infant_004` 어린이집 최고 목청, `child_018` 응원단장 스카우트, `teen_006` 점심 방송 사고, `adult_031` 결혼식 사회 부탁 | 맞음. 네 사건 모두 **큰 목소리**가 핵심이라 이름보다 설명문("어디서든 목소리가 크고 …")이 연결 고리다. 설명문의 목소리 표현은 지워지지 않게 유지 요청 |
| 파고드는 편 (`starter_curious`) | `infant_003` 리모컨의 비밀, `child_020` 고장 난 시계 해부, `teen_024` 선생님의 오답, `adult_025` 특허가 될지도 모르는 아이디어 | 맞음. 뜯어보고 끝까지 알아내는 행동 |
| 엉뚱한 편 (`starter_quirky`) | `infant_016` 거꾸로가 좋아, `child_007` 장래 희망 발표, `teen_002` 거꾸로 입은 교복, `adult_029` 휴가 사유란 | 맞음. 남다른 생각과 황당한 일 |

- 사건 본문·선택지·결과 문장에 `기질`, `우렁찬`, `골똘한`, `엉뚱한 아기`는 0건이다.
- `yearly_stories.sample.json`, `titles.sample.json`, `endings.sample.json`, `life_facts.sample.json`에도 옛 용어가 없다.

## 4. 선택지 보조 태그를 줄일 때의 표현

지금 선택지 카드는 `라벨` 아래에 `가능성 … · 사회성 · 행복` 한 줄과 초록/빨강 `건강 +N 회복/감소` 줄을 보여 준다(`PeriodPlayUi.kt` `hint()`, `healthEffectText()`). 요구 7에 따라 이 보조 줄을 접거나 약하게 할 때 의미가 사라지지 않게 하는 문장 쪽 기준을 제안한다.

### 4-1. 쓰기 원칙

1. **선택지 라벨은 행동 그대로** 쓴다. 능력치 이름을 라벨에 붙이지 않는다(`사회성을 위해 ~` 금지). 지금 라벨 1,009개는 대부분 이미 행동문이다.
2. **결과 문장이 변화의 이유를 말로 보여 준다.** 가장 큰 변화(주 효과)가 무엇 때문에 생겼는지 한 구절이 들어가면 숫자 애니메이션이 사라진 뒤에도 남는다. 예: `지력 +4` → "책 읽는 시간이 저절로 늘었다."
3. **`가능성 높음/보통/낮음` 한 단어는 접지 않는 편을 권한다.** 숨은 결과가 있는 선택의 위험을 알려 주는 유일한 표시이고, 능력치 이름보다 짧다. 능력치 이름(`사회성 · 행복`)만 접어도 카드가 가벼워진다.
4. **건강 표시**는 색만으로 구분하지 말고 `건강 회복`/`건강 감소` 글자를 유지한다(색각 이상·TalkBack). 크기와 색 대비는 라벨보다 약하게.
5. 숨은 결과의 문장·확률·능력치는 선택 전에 쓰지 않는 기존 규칙(R-44)을 그대로 지킨다.

### 4-2. 결과 애니메이션의 정적 대체·접근성 문장표 (요구 9)

`건강 +3` 같은 숫자가 짧게 떴다 사라질 때, 애니메이션을 끈 환경과 TalkBack에서 함께 읽을 문장이다. 숫자 표시는 그대로 두고 뒤에 붙인다.

| 능력치 | 올랐을 때 | 내렸을 때 |
| --- | --- | --- |
| 건강 | 몸이 한결 개운해졌다 | 몸이 조금 무거워졌다 |
| 지력 | 머리가 조금 더 맑아졌다 | 생각이 조금 흐트러졌다 |
| 사회성 | 사람들과 조금 더 가까워졌다 | 사람들과 조금 멀어졌다 |
| 행복 | 기분이 좋아졌다 | 마음이 조금 가라앉았다 |
| 운 | 운이 따르는 기분이다 | 운이 살짝 비껴갔다 |
| 운동능력 | 몸이 더 잘 움직인다 | 몸이 조금 굳었다 |
| 경제력 | 주머니가 조금 두둑해졌다 | 지갑이 조금 가벼워졌다 |

- 크기 말: ±1~2는 `조금`, ±3~5는 그대로, ±6 이상은 `크게`(예: `건강 -6` → "몸이 크게 무거워졌다").
- 여러 능력치가 바뀌면 큰 순서로 두 개까지만 읽고 나머지는 `그 밖에 N가지가 바뀌었다`로 줄인다.
- 건강이 0이 되어 사망하는 결과는 이 문장 대신 사망 결과 문장을 먼저 읽는다(기존 사망 처리 유지).
