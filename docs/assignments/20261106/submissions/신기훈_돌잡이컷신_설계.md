# 돌잡이 컷신 설계 (요구 6)

작성: 신기훈 (시나리오·의미 검수) · 2026-11-07 · 기준 `main` `71493fe`

## 1. 위치와 범위

- 게임 시작 → 주사위·성향 결정 → **영아기 1번째 해 첫 결정 `infant_007` 돌잡이** 바로 앞에 컷신을 넣는다.
- 컷신은 **보여 주기만** 한다. 능력치·플래그·`lifeDelta`·칭호·기록은 지금처럼 `infant_007`에서 선택지를 고른 뒤 엔진이 한 번만 반영한다.
- 컷신 문장과 그림은 세 물건(피아노 장난감·판사봉·5만 원권) 중 **어느 것도 고르거나 강조하지 않는다**.
- 동영상 파일이 아니라 Compose 연출 또는 순차 컷 PNG(4:3, 중앙 안전영역)로 오프라인에서 동작한다.

## 2. 컷 구성 (5컷)

대사·내레이션은 그림에 굽지 않고 화면 글자로 올린다. `{name}`은 이름, `{nameCall}`은 부르는 말(민지야, 준호야)이다.

| 컷 | 장면 (1인칭 영아 시점) | 화면 문구 | 길이 | 접근성 설명 |
| --- | --- | --- | --- | --- |
| 1 | 집 거실 돌상 앞. 떡·과일이 놓인 낮은 상, 글자 없는 장식 가랜드, 한복 소매 끝의 작은 아기 손 | 내레이션: 오늘은 {name}의 첫 생일이다. | 2초 또는 탭 | 돌상이 차려진 거실. 한복을 입은 아기의 손이 보인다. |
| 2 | 둘러앉은 가족들(어른 여럿, 구성·성별 고정 없음)이 휴대폰을 들고 아기를 바라봄 | 가족: "우리 {nameCall}, 벌써 돌이네." | 2초 또는 탭 | 가족들이 웃으며 휴대폰으로 아기를 찍으려 한다. |
| 3 | 사회자가 빈 쟁반을 들고 앞으로 나옴. 쟁반 위는 아직 천으로 덮여 있음 | 사회자: "자, 오늘의 순서! 돌잡이 시간입니다~" | 2초 또는 탭 | 사회자가 덮개 씌운 쟁반을 들고 다가온다. |
| 4 | 아기 앞 바닥 천 위에 피아노 장난감·판사봉·5만 원권이 **같은 크기·같은 간격·같은 밝기**로 한 줄로 놓임. 아기 손은 아직 무릎 위 | 내레이션: 눈앞에 세 가지 물건이 놓였다. | 2.5초 또는 탭 | 피아노 장난감, 판사봉, 5만 원권이 나란히 놓여 있다. |
| 5 | 가족들이 숨을 죽이고 몸을 앞으로 기울임. 사회자 손이 세 물건 쪽을 가리킴 | 내레이션: 온 가족이 숨을 죽였다. | 2초 또는 탭 | 가족들이 조용히 아기를 지켜본다. |

5컷이 끝나면 기존 `infant_007` 결정 화면(제목 `돌잡이`, 본문 `사회자: "자~ {name} 아기, 무엇을 잡을까요~?" …`)으로 넘어간다. 본문의 사회자 대사와 겹치지 않게 컷 5에는 사회자 대사를 넣지 않았다.

### 컷마다 금지

- 아기가 물건을 잡거나 손을 뻗는 모습, 박수·환호, 피아노 소리, 판사봉 두드리기, 돈을 쥔 손 (선택 결과)
- 특정 물건만 가운데·크게·밝게·빛나게 두기, 물건 위 화살표나 강조 테두리
- 능력치 이름·숫자·아이콘, 성향 이름 (`활발한 편` 등) — 성향은 이미 시작 화면에서 보여 줬다
- 아기 얼굴·거울·창 반사 (1인칭 유지), 현수막의 `첫돌` 같은 글자, 실존 브랜드
- 특정 가족 구성 단정 (엄마·아빠·조부모가 반드시 다 있다는 그림) — 컷 2·5는 "어른 여럿"으로 둔다. 본문의 할아버지(판사봉 결과)·엄마(5만 원 결과)는 결과 문장에서만 나온다

## 3. 진행·상태 규칙 (김우영·김재겸 구현 기준 제안)

| 상황 | 기대 동작 |
| --- | --- |
| 컷 진행 | 자동 2초 또는 화면 한 번 탭으로 다음 컷. 화면 문구가 타이핑 중이면 첫 탭은 문구 전체 표시(기존 규칙과 같음) |
| 건너뛰기 | 모든 컷에 `건너뛰기` 버튼. 누르면 바로 `infant_007` 결정 화면. 능력치 변화 없음 |
| 애니메이션 끔(reduce motion) | 컷을 정지 그림으로 보여 주고 `다음` 버튼으로 넘김. 문구와 접근성 설명은 같음 |
| 컷신 도중 앱 종료 → 이어하기 | 컷 1부터 다시 보여 주거나 바로 결정 화면. 어느 쪽이든 능력치·플래그는 그대로 |
| 결정 후 이어하기 | 컷신을 다시 보여 주지 않는다 (결과 화면 복원 규칙 유지) |
| 새 인생 시작(재시작) | 컷신을 다시 보여 준다. 이전 인생의 보상이 남거나 두 번 들어가면 안 된다 |
| 선택 | `infant_007` 선택은 기존처럼 한 번만 반영. 컷신 완료 여부는 표시용 상태이고 저장 계약(보상·사망 판정)에 넣지 않는다 |

## 4. 테스트 체크리스트 (김선한 QA 매트릭스용)

1. 컷 1~5를 지나는 동안 능력치 7개와 플래그가 시작 값과 같다.
2. 컷 3에서 건너뛰기 → 결정 화면, 능력치 변화 없음.
3. 컷 4에서 앱 종료 → 이어하기 → 능력치 변화 없음, 결정 화면 또는 컷 1.
4. `판사봉을 잡는다` 선택 → `지력 +4` 등 결과가 한 번만 반영, 이어하기로 다시 들어가도 두 번 반영되지 않음.
5. 새 인생 시작 → 컷신이 다시 나오고, 이전 인생의 `judge_gavel` 같은 플래그가 남지 않음.
6. TalkBack으로 컷마다 접근성 설명이 읽힌다.

## 5. 그림 주문 (정원률 님 화풍·프레임 설계용)

- 5컷 모두 4:3 원본, 도트풍, 중앙 안전영역(가로 약 34~66%)에 핵심을 둔다.
- 컷 4의 세 물건은 **세 개가 모두 세로 크롭 안에 들어가게** 좁게 모은다. 하나만 크롭 밖으로 나가면 그 물건을 덜 고르게 되는 쏠림이 생긴다.
- `infant_007`의 사건 그림 ID `img_infant_toys_001`은 카탈로그에만 있고 PNG 파일이 아직 없다(2026-11-07 `main` 확인). 컷 4 그림을 이 사건 그림으로 함께 쓰면 컷신 → 결정 화면이 같은 물건 모양·색으로 이어지고 그림 한 장을 줄일 수 있다. 연결(라우팅)은 의미·크롭 검수 뒤 김선한 님이 결정한다.
- 컷 수를 줄여야 하면 컷 1+2, 컷 3+4를 합쳐 3컷으로 줄일 수 있다. 컷 4(세 물건이 공평하게 놓인 장면)는 빼지 않는다.
