## 2. 스탯·보상을 미리 확정하는지 (요구 3 검수)

**결론: 설계와 상태 계약 모두 미리 확정하지 않는다.** 단, 그림과 연결 방식에서 쏠림이 생길 수 있는 4곳을 막아야 한다.

| 확인 | 판정 | 근거 |
| --- | --- | --- |
| 컷신이 능력치·플래그·`lifeDelta`·칭호를 바꾸는가 | 안 바꿈 | `setCutsceneStatus`는 `presentationForRun`만 바꾼다. 보상은 `infant_007` 선택 뒤 엔진이 한 번 적용(A 행복+4·지력+2·사회성−2, B 지력+4·사회성+1·행복−2, C 운+4·사회성+1·행복−3 또는 25% `c_double`) |
| 컷 그림이 한 물건을 고른 것처럼 보이는가 | 안 보임 | 정원률 배치도는 세 물건이 같은 크기·간격·밝기, 손·잡는 동작 없음 |
| 컷 문구가 결과를 말하는가 | 안 말함 | 그림에 글자 없음, 캡션은 생일 사실 한 줄뿐(3장) |
| 건너뛰기·재시작이 보상을 두 번 주는가 | 안 줌 | 보상은 선택에만 붙어 있고, 컷신은 선택 전에 끝난다 |

### 막아야 할 쏠림 4곳

1. **5만 원권은 한 장만.** 선택 C의 숨은 결과 `c_double`은 "할아버지가 몰래 한 장을 겹쳐 둔" 두 장이다. 컷에 지폐가 두 장 보이면 그 결과를 미리 보여 준다.
2. **할아버지·엄마를 물건 옆에 두지 않는다.** B 결과에 할아버지(법률 동화 전집), C 결과에 엄마(돈을 가져감)가 나온다. 가족은 뒤에서 지켜보는 어른 여럿으로만 두고, 특정 인물이 특정 물건을 가리키거나 손에 쥐지 않게 한다.
3. **컷 그림을 사건 그림으로 같이 쓰면 세로 크롭에서 쏠린다.** 컷신은 4:3 전체를 보여 주므로 가로 15–85% 배치가 괜찮지만, 결정 화면의 장면 보기·선노출은 가운데 약 33–67%만 보인다. 같은 PNG를 `img_infant_toys_001`로 쓰면 피아노·5만 원권이 잘리고 판사봉만 남아 B로 쏠린다. 같이 쓰려면 세 물건을 가로 34–66% 안으로 좁힌 판을 따로 만든다.
4. **선노출과 겹치지 않게.** 요구 8(사건 이미지 선노출)이 붙으면 컷신 뒤 `infant_007` 결정 화면에서 같은 돌잡이 그림이 한 번 더 나온다. 컷신을 끝내거나 건너뛰면 `markEventImageShown("infant_007")`을 같이 불러 선노출을 한 번 건너뛰거나, 컷신 그림을 선노출로 쓴다(둘 중 하나, 김재겸 결정).

## 3. 장면과 문구 (요구 4 보완)

| 순서 | 내용 |
| --- | --- |
| 그림 | 정원률 1컷: 영아 눈높이 돌상 앞, 피아노 장난감·판사봉·5만 원권(한 장) 나란히, 뒤에 지켜보는 어른들 |
| 화면 캡션 (그림 밖, 한 줄) | `오늘은 {name}의 첫 생일이다.` |
| 접근성 설명 | `돌상 앞에 피아노 장난감, 판사봉, 5만 원권이 나란히 놓여 있다. 가족들이 숨죽여 지켜본다.` |
| 다음 화면 | `infant_007` 결정 화면. 본문 `사회자: "자~ {name} 아기, 무엇을 잡을까요~?" … 온 가족이 숨을 죽였다.`가 타이핑으로 이어진다 |

- 11/07 초안의 사회자 대사·"숨을 죽였다" 내레이션은 **결정 본문에 이미 있어서 컷신에서 뺐다**. 같은 말이 두 번 나오지 않는다.
- 캡션을 빼도 의미는 남는다(그림 + 결정 본문). 2초 안에 읽을 수 있는 길이가 한 줄이 한계라서 대사를 더 넣지 않는다.
- `{name}`이 비어 있으면 `오늘은 첫 생일이다.`로 쓴다.

## 4. 진행 규칙 (상태 계약 기준)

| 상황 | 조건 | 컷신 상태 | 화면 | 엔진 |
| --- | --- | --- | --- | --- |
| 시작 | 대기 중인 결정이 `infant_007`이고 상태가 `NOT_STARTED` | `PLAYING`으로 바꾸고 재생 | 컷 1장, 캡션, 건너뛰기 | 변화 없음 |
| 자동 끝 | 2초 경과 | `COMPLETED` | `infant_007` 결정 화면 | 변화 없음 |
| 탭 | 재생 중 한 번 탭 | `COMPLETED` | 결정 화면 | 변화 없음 |
| 건너뛰기 | 버튼 | `SKIPPED` | 같은 결정 화면 | 변화 없음 |
| 움직임 줄이기·TalkBack | 시스템 설정 | 자동 넘김 끔 | 정지 그림 + `계속` 버튼, 접근성 설명 읽기 | 변화 없음 |
| 재생 중 앱 종료 → 이어하기 | 저장된 상태가 `PLAYING` | 다시 `PLAYING` | 처음부터 한 번 더 재생 | 변화 없음 |
| 이어하기 | 저장된 상태가 `COMPLETED`·`SKIPPED` | 그대로 | 바로 결정 화면 | 변화 없음 |
| 선택 뒤 이어하기 | 대기 결정이 `infant_007`이 아님(결과 복원 등) | 상관없음 | 재생 안 함 | 변화 없음 |
| 옛 저장(v1~v3) | 상태 기본값 `NOT_STARTED` | 대기 결정이 `infant_007`일 때만 재생 | 이미 지난 저장은 조건이 안 맞아 재생 안 함 | 변화 없음 |
| 새 인생 | `PresentationState()` | `NOT_STARTED` | 첫 결정 앞에서 다시 재생 | 새 상태(이전 플래그 없음) |
| 콘텐츠가 바뀌어 1년 차 첫 결정이 돌잡이가 아님 | 조건 불일치 | 그대로 | 재생 안 함 | 변화 없음 |

- 재생 조건은 **연도가 아니라 `eventId == "infant_007"`**로 건다. 옛 저장과 콘텐츠 변경에서 엉뚱한 사건 앞에 돌잡이가 나오지 않는다.
- 2초 자동 넘김과 첫 탭이 동시에 들어와도 `COMPLETED`는 한 번만 기록한다(이미 `COMPLETED`·`SKIPPED`면 무시).

## 5. 테스트 체크리스트 (김선한 QA 매트릭스용, 11/07판 갱신)

1. 새 인생 → 주사위 → 컷신 재생, 컷신 동안 능력치 7개·플래그가 주사위 결과와 같다.
2. 건너뛰기 → `SKIPPED`, 결정 화면, 능력치 변화 없음.
3. 재생 중 앱 종료 → 이어하기 → 컷신 한 번 더, 능력치 변화 없음.
4. `COMPLETED` 뒤 앱 종료 → 이어하기 → 컷신 없이 결정 화면.
5. `판사봉을 잡는다` 선택 → 지력 +4 등 결과 한 번만, 결과 화면에서 이어하기로 다시 들어가도 두 번 적용되지 않음.
6. 새 인생 다시 시작 → 컷신 다시 재생, 이전 인생의 `judge_gavel`·`cash_grabber` 플래그 없음.
7. 컷신 뒤 결정 화면에서 같은 돌잡이 그림이 선노출로 한 번 더 나오지 않음(2장 4번).
8. 움직임 줄이기 켬 → 정지 그림 + `계속`, TalkBack이 접근성 설명을 읽음.
9. 컷 그림에 5만 원권 한 장, 손·잡는 동작·글자 없음(의미 검수, 신기훈).

## 7. 11/07 초안과 달라진 점

- 5컷 → **1컷**(정원률 #60 확정안에 맞춤). 컷 1~5의 대사 대신 캡션 1줄.
