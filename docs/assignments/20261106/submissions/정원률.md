# 11주차 정원률 제출 · UI·이미지·화풍

2026-11-07 · 개인 검수 정리

## 1. UI 시각 기준

- 기본 글씨 배율 **100%**에서 기존 본문 17sp, 선택지 16sp, 결과 본문 16.5sp를 유지한다. 긴 문장은 세로로 읽을 수 있게 줄을 바꾸고, 마지막 선택지와 계속 버튼이 스크롤로 도달 가능한지 본다.
- 선택지의 행동 문구를 우선 읽히게 한다. 보조 태그와 건강 증감은 낮은 강조로 두고, 잠금 이유는 읽을 수 있게 유지한다.
- 결과 변화의 시각 제안은 카드 위에서 **약 1.2초** 표시한 뒤 사라지는 것이다. 결과 본문과 버튼은 제자리에 있고, 움직임 줄이기에서는 결과 카드에 정적으로 표시한다.

Pixel 9 기본 배율 실제 화면 · [선택지](wonryul-evidence/ui-decision-100.png) · [결과](wonryul-evidence/ui-outcome-100.png). 두 캡처는 기존 앱 화면이며 결과 애니메이션은 구현용 시각 기준이다.

## 2. 시작 돌잡이 컷신 설계

검수 확정은 **고정 1컷, PNG 1프레임, 총 2초**다. 처음 0.2초 동안 그림이 나타나고 1.8초 유지 후 기존 선택 화면으로 간다. 아이 눈높이에서 피아노 장난감·판사봉·5만 원권을 한 장에 담는다. 세 물건은 원본 가로 15–85%, 세로 25–75% 안에 두고 4:3 원본 전체를 표시한다.

화풍은 영아기 장면의 따뜻한 갈색·종이색과 또렷한 픽셀 경계를 따른다. 건너뛰기는 동일한 선택 전 상태로 연결하고, 움직임 줄이기에서는 정지 이미지와 계속 버튼을 표시한다. 그림 안에는 대사나 버튼을 넣지 않는다. [검수한 구도 배치도](wonryul-evidence/cutscene-layout.png)

## 3. 얼굴과 사건 이미지 검수

- **6시기 얼굴** · Pixel 9의 64×72dp 초상에서 머리끝과 턱이 보였다. 청소년·청년 차이는 수용했다. 노년 기본 눈의 반사광을 작게 보완하는 수정 의견을 남겼다. [실제 얼굴 캡처](wonryul-evidence/faces-emulator.png)
- **사진 합성** · 가상 얼굴 시트로 검수했다. 몸 피부색을 달리하면 목·손과 얼굴이 분리되어 보여 적용 전 전신 미리보기를 제안했다. [피부색 비교](wonryul-evidence/faces-skin-comparison.png)
- **사건 이미지** · 제작분 65장의 원본과 360×800 가운데 잘림을 비교했다. 도트풍과 1인칭 구도를 공통 기준과 대조했다. 시계 해부·합창 대회·빚 정리·자동문은 우선 보완했고, 실제 앱 미리보기에서 재확인한 수영 대회와 점심 방송도 보완했다. 교복은 손가락과 소맷단이 구분돼 유지했다.

[승인 후 교체한 6장의 세로 예상 비교](wonryul-evidence/images-six-revisions.png) · 원본의 실제 앱 미리보기 [수영](wonryul-evidence/images-swim-emulator.png), [교복](wonryul-evidence/images-uniform-emulator.png), [방송](wonryul-evidence/images-broadcast-emulator.png). 수정본 6장은 4:3 원본이며 비교 이미지는 세로 표시 예상이다.

## 4. PNG 제출 상태
