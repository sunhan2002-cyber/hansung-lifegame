## 1. UI 시각 기준

- 기본 글씨 배율 **100%**에서 기존 본문 17sp, 선택지 16sp, 결과 본문 16.5sp를 유지한다. 긴 문장은 세로로 읽을 수 있게 줄을 바꾸고, 마지막 선택지와 계속 버튼이 스크롤로 도달 가능한지 본다.
- 선택지의 행동 문구를 우선 읽히게 한다. 보조 태그와 건강 증감은 낮은 강조로 두고, 잠금 이유는 읽을 수 있게 유지한다.
- 결과 변화의 시각 제안은 카드 위에서 **약 1.2초** 표시한 뒤 사라지는 것이다. 결과 본문과 버튼은 제자리에 있고, 움직임 줄이기에서는 결과 카드에 정적으로 표시한다.

Pixel 9 기본 배율 실제 화면 · [선택지](wonryul-evidence/ui-decision-100.png) · [결과](wonryul-evidence/ui-outcome-100.png). 두 캡처는 기존 앱 화면이며 결과 애니메이션은 구현용 시각 기준이다.

### 사건 이미지 선노출 종료 후 스크롤

11월 9일 정원률 검수 확정 의견이다. 선노출 시간이 끝나면 본문 위치를 유지한다. 사용자가 이미지의 **‘누르면 선택지로’**를 눌렀을 때는 첫 선택지 카드가 화면 아래에 가려진 경우에만 선택지 영역으로 이동한다. 첫 카드가 전부 보이면 현재 위치를 유지하고, 선택은 카드에서 별도로 한다.

김재겸은 360×640dp·글자 크기 130%의 에뮬레이터에서 돌잡이 첫 선택지의 윗부분만 보이는 것을 확인했다. PR #61의 최신 구현(`5ddaa15`)은 첫 카드가 잘릴 때 선노출이 자동으로 끝나도 스크롤한다. 위 기준에 맞춘 프런트엔드 반영과 360×640dp·글자 크기 100% 및 130%에서의 동작 확인은 김재겸 구현 단계로 남긴다. [작은 화면 검증 기록](https://github.com/sunhan2002-cyber/hansung-lifegame/blob/1dd9a827de5fb67f102baaed7f560c3e337e1d70/docs/assignments/20261106/submissions/%EA%B9%80%EC%9E%AC%EA%B2%B8.md#L106) · [PR #61 스크롤 구현](https://github.com/sunhan2002-cyber/hansung-lifegame/pull/61/commits/5ddaa15912a4f120925a7f03ed88d56d5fa78178)

## 2. 시작 돌잡이 컷신 설계

검수 확정은 **고정 1컷, PNG 1프레임, 총 2초**다. 처음 0.2초 동안 그림이 나타나고 1.8초 유지 후 기존 선택 화면으로 간다. 아이 눈높이에서 피아노 장난감·판사봉·5만 원권을 한 장에 담는다. 세 물건은 원본 가로 15–85%, 세로 25–75% 안에 두고 4:3 원본 전체를 표시한다.

화풍은 영아기 장면의 따뜻한 갈색·종이색과 또렷한 픽셀 경계를 따른다. 건너뛰기는 동일한 선택 전 상태로 연결하고, 움직임 줄이기에서는 정지 이미지와 계속 버튼을 표시한다. 그림 안에는 대사나 버튼을 넣지 않는다. [검수한 구도 배치도](wonryul-evidence/cutscene-layout.png)

11월 9일 원률 검수를 거쳐 [실제 컷신 PNG 1장](../../../../app/src/main/assets/images/cutscenes/week11/img_doljabi_intro_001.png)을 추가했다. 1448×1086, 4:3 전체 표시용이며, 피아노 장난감·판사봉·5만 원권 한 장을 선택 전에 함께 보여준다. [리소스 경로·해시·재생 기준](정원률_돌잡이컷신_manifest.json). 컷신 화면 연결은 대기 상태다.
