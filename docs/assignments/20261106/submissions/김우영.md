## 구현 내용

- 사진 동의·권한·처리 실패 상태를 `PhotoFlowStatus`로 분리했다.
- 돌잡이 컷신 상태를 `CutsceneStatus`로 저장하며 보상 상태와 분리했다.
- 사건 이미지 선노출 상태를 사건 ID와 함께 저장하고, 같은 사건의 표시 완료가 복원 후 다시 대기로 돌아가지 않게 했다.
- 선택 결과 애니메이션을 `resultDisplayId` 기반 순수 표시 이벤트로 만들었다. 애니메이션 확인은 엔진 선택·능력치 반영을 다시 호출하지 않는다.
- 자동 연도 이야기와 선택 결과를 `RunNarrativeKind`로 구분해 실제 표시 문장 그대로 저장한다.
- 선택 결과 기록에는 원본 사건 ID와 선택지 ID를 필수로 두어 출처 없는 결과 문장을 기록할 수 없게 했다.
- `recordId` 기반 `appendOnce`로 화면 복원·반복 호출에도 같은 기록이 중복되지 않게 했다.
- 저장 형식을 v4로 올리고 v1~v3 저장은 새 표시 상태와 기록이 기본값인 상태로 계속 읽는다.
- 주사위 초기 스탯, 건강·생존·사망 판정, 실제 보상 계산은 변경하지 않았다.
