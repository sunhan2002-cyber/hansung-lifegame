## 2. 사건 이미지 선노출

순서: 제목 · 본문 타이핑 → (0.6초 뒤) 사건 그림 선노출 → 선택지.

- 선노출: 배경 블러를 풀고 UI를 숨긴 채 아래에 제목과 "누르면 선택지로"만 둔다. 2.5초가 지나거나 한 번 누르면 선택지로 넘어간다. 뒤로 가기도 같다.
- 보존한 규칙
  - 타이핑 중 어디를 눌러도 본문 전문만 표시(선택 · 장면 보기 · 진행으로 가지 않음). 본문이 나오는 동안에는 선택지 · 장면 보기 버튼 자체가 없다.
  - 선노출을 끝내는 터치에 곧바로 이어진 연타는 300ms 동안 삼킨다(선택지가 잘못 눌리지 않음).
  - 장면 보기 버튼은 선노출 뒤에만 보이고, 기존대로 블러 해제 · UI 숨김 · 한 번 터치 복귀. 복귀해도 다시 타이핑하거나 선노출을 다시 띄우지 않는다.
  - 복원(화면 회전 · 프로세스 복원)에서도 타이핑 · 선노출을 반복하지 않는다(`rememberSaveable`).
  - 선택은 한 번만: 카드가 첫 터치만 넘기고(`chosenId`), VM도 결과가 있으면 무시한다.
  - 결과 화면은 선노출 없이 바로 보인다.
- 그림이 없는 사건은 기존 라우팅의 안전 대체 그림(시기 · 능력치 배경)을 선노출한다. 전용 그림 승인 현황은 `validate_followup_image_coverage.py` 기준 승인 16사건 / 대기 336사건으로, 대체 그림 사건은 미완료로 남는다(아래 6).
- 코드: `screens/DecisionScreen.kt` (`PREVIEW_DELAY_MILLIS` 600, `PREVIEW_HOLD_MILLIS` 2500, `ScenePreview`).

## 3. 선택지 카드

- 제목(행동) 17sp 굵게가 가장 크다. 그 아래 한 줄 보조 정보: `가능성 높음 · 건강 +10`(13sp, 흰색 68% 투명도, **초록 · 빨강 색 없음**).
- 사회성 · 행복 같은 능력치 태그는 기본으로 접는다. 위의 `능력치 영향 보기` 버튼으로 펼치면 `영향: 사회성 · 행복`이 보인다(사건이 바뀌어도 펼침 상태 유지).
- 접근성: 카드 설명에 접힌 태그까지 포함(`선택지 A. 봉사를 나간다. 가능성 높음. 능력치 영향 사회성, 행복. 건강 +10 회복`), 클릭 라벨 `이 선택지로 결정`, 잠김 · 선택함 상태 설명.
- 상태: 누르는 동안 카드가 밝아지고 0.985배로 살짝 눌리며 테두리가 진해짐. 고른 카드는 두꺼운 테두리, 나머지는 흐려짐.
- 코드: `screens/DecisionScreen.kt`(`DecisionChoiceCard`, `ChoiceDetailsToggle`), `PeriodPlayUi.kt`(`DecisionChoiceUi.likelihood` · `statTags`).

## 4. 결과 변화 애니메이션

- 선택 직후 결과 카드 위에 `건강 +3`, `지력 −2` 칩이 아래에서 떠오르며(fade + slide 260ms) 1.6초 떠 있다가 위로 사라진다(320ms). 고정 문구로 남지 않는다.
- 순수 표시용: 반영은 VM에서 이미 한 번 끝났다. 같은 결과에서는 다시 재생하지 않는다(`rememberSaveable`, 재구성 · 복원 포함).
- 스크린리더: 칩 묶음이 나타날 때 `능력치 변화: 건강 +3, 지력 −2`를 한 번 읽는다(liveRegion Polite).
- 동작 줄이기(애니메이션 배율 0): 애니메이션 대신 기존 고정 문구(`outcome_stat_changes`)를 바로 보여 준다.
- 사망 결과(`인생 정리하기`)도 같은 표시 경로라 반영 횟수에 영향이 없다.
