## APK·보안 확인

- Debug APK: `app/build/outputs/apk/debug/app-debug.apk`
- Release APK: `app/build/outputs/apk/release/app-release-unsigned.apk`
- Release는 **서명되지 않은 unsigned APK**이므로 배포용이 아니라 로컬 설치·시연 후보로만 분류한다.
- `local.properties`는 추적되지 않으며 `OPENAI_API_KEY`가 현재 저장되어 있지 않다.
- `BuildConfig.DEBUG` 조건으로 개발용 디자인 미리보기·생성 버튼은 Debug에서만 노출된다.
- 현재 셸에서 `adb`가 PATH에 없어 에뮬레이터 설치·터치 검증은 실행하지 못했다.
