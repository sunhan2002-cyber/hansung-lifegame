**제안:** 승인 원본과 그 SHA-256을 보존한다. 이번 무손실 방식은 표본에 따라 파일이 커지거나 약 5~9% 작아졌고, 세 장 모두 SHA-256이 달라졌다. APK 용량 때문에 더 작은 파일이 필요한 경우, 후보를 원본과 별도로 만들어 실제 대상 화면에서 의미·화풍·핵심 사물을 검수한 뒤 승인된 배포본의 SHA-256과 라우팅을 함께 기록한다. 기존 720×540 두 장의 SHA-256은 [재검수표](정원률_김재겸_재검수_20261113.csv)에 있다.

## 7. 돌발 사건 이미지 선노출 화면 검수

main `ca0bec6`과 동일한 사건 화면에서 `special_005` **나를 거부하는 자동문**을 확인했다. 실제 사건 콘텐츠와 이미지 경로를 사용해 에뮬레이터에서 팝업, 본문, 그림, 선택지 화면을 차례로 캡처했다. 검수용 상태로 해당 사건 화면을 열었으며 새 게임부터 사건이 발생하기까지의 진행은 이번 검수 범위 밖이다.

| 화면 (글자 크기 100%) | 그림과 가독성 | 표시 순서 |

| 1080×2400, 420 dpi | 검은 띠 없이 화면을 채운다. 자동문, 센서, 박수 치는 학생이 식별된다. 센서 오른쪽 끝과 가까운 학생의 외곽은 일부 잘린다. 하단 제목과 안내가 읽힌다. | 수정 필요. **사건 보기** 직후 본문 타이핑, 본문 완료 후 그림, 이후 선택지 순서였다. |
| 720×1280, 320 dpi (360×640 dp) | 검은 띠 없이 화면을 채우고 센서와 학생의 박수 동작이 보인다. 하단 제목과 안내가 읽힌다. | 긴 화면과 같은 순서였다. |

**정원률 검수 완료 (2026-11-14), 김재겸 수정 요청:** 돌발 팝업에서 **사건 보기**를 누르면 현재 사건의 선명한 그림을 바로 표시한다. 그림 단계가 끝난 뒤 본문 타이핑을 시작하고, 본문이 끝난 뒤 선택지를 표시한다. 그림 아래의 **누르면 선택지로** 안내와 접근성 설명도 실제 다음 단계인 본문에 맞춘다. 그림을 넘기는 터치가 선택을 확정하지 않는지 두 화면 크기에서 재확인한다.

두 크기에서 각각 현재 순서를 확인하는 검수 실행 1회가 끝났고, 그림을 넘기는 터치만으로는 선택이 확정되지 않았다. 실제 화면 캡처와 실행 로그는 저장소 밖 `incident-preview-20261113/1080x2400`, `720x1280`에 보관했다. 에뮬레이터 해상도·밀도·글자 크기를 복원했다. 앱과 사건 PNG는 기존 파일을 사용했다.

## 8. 주사위 초기 능력치 화면 검수

2026-11-14에 [PR #74](https://github.com/sunhan2002-cyber/hansung-lifegame/pull/74)의 제출 버전 `f87a0adde175d172fc3ac6fe6c4fddb84a8b3b71`을 별도 폴더에서 빌드했다. Pixel 9 에뮬레이터의 **새 인생 살기 → 주사위 굴리기**로 실제 프로필 화면을 확인했다.

| 화면 (글자 크기 100%) | 표시 확인 |
| --- | --- |
| 720×1280, 320 dpi (360×640 dp) | 주사위 영역으로 스크롤하면 여섯 항목의 이름·두 눈·합계·최종값이 각각 한 줄에 보인다. 두 자리 합계인 `5+5=10 → 56`도 잘리지 않는다. |
| 1080×2400, 420 dpi | 여섯 항목이 모두 읽히며, `6+6=12 → 60`과 `3+1=4 → 44`도 잘리지 않는다. |

두 화면에서 읽어낸 12개 결과의 합계와 최종값이 `두 눈의 합`, `50 + (합계 - 7) × 2`와 각각 일치했다. 시작 코드가 동일한 보정치를 기본 스탯 50에 적용하는 것도 확인했다. 기기 검수는 프로필 표시까지 진행했다.

**정원률 검수 완료 (2026-11-14), 수정 의견:** 현재 `3+1=4 → 44`에는 합계와 최종값이 모두 보이지만, 기본값 50과 보정 −6이 빠져 44가 나온 이유를 알기 어렵다. 통합지시서의 음수 보정 전후 표시 기준에 맞춰 **3 + 1 = 4 / 기본 50 − 6 = 최종 44**처럼 함께 보여준다. 계산 규칙을 짧게 한 번 안내하고, 작은 화면에서 줄이 늘어도 항목명과 수치가 잘리지 않는지 재확인한다.

검수용 앱 빌드와 두 화면의 검수 실행이 통과했다. 화면 캡처, 표시값, 실행 로그는 저장소 밖 `dice-review-20261114`에 보관했다.
