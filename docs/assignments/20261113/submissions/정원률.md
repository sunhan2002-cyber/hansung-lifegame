- **정원률 검수 완료 (2026-11-16), 수정 의견 (김재겸 담당).** 결과 카드에 선택 연도가 표시되지 않는다. 이어하기에서 선택을 저장한 시기는 유년기 5번째 해로 남아 있지만, 결과 화면에 전달되는 연도 값이 1번째 해로 바뀐다. 저장한 시기와 연도를 복원하고 카드에서 **유년기 5번째 해**처럼 읽을 수 있게 한다.

같은 재개 절차를 두 화면 크기에서 재현했다. 화면 캡처와 실행 로그는 저장소 밖 `outcome-main-review-20261116`에 보관했다.

## 20. 자동 소사건 카드와 돌발 사건 그림 구분 검수 (2026-11-16)

[김재겸 PR #79 `e7d1c00`](https://github.com/sunhan2002-cyber/hansung-lifegame/pull/79) 검수 빌드를 Pixel 9 에뮬레이터 720×1280(320 dpi), 1080×2400(420 dpi), 글자 100%에서 확인했다. 새 인생 돌잡이에서 피아노를 고르고 다음 해로 진행했다.

- **자동 소사건 `auto_infant_dol_photo_music`.** **자동 · 돌잡이 회상** 카드에서 본문과 **능력치 변화 없이 기록에만 남겼어요**, 실제 선택을 반영한 피아노 회상이 읽혔다. 카드 아래 그림은 일반 영아기 진행 배경이다. 작은 화면에서는 이 배경이 가로 띠로 줄어들고, 카드의 본문과 회상은 끝까지 보인다. 이 단계에 돌발 팝업이나 사건 그림 전체 보기는 나오지 않았다.
- **뒤이은 돌발 `infant_026`.** 자동 카드가 사라지고 **볼풀에서 잃어버린 신발** 팝업이 볼풀 그림을 배경으로 자동 표시됐다. **사건 보기**를 누르면 등록된 `img_infant_ball_pit_001`이 먼저 열렸다. 두 크기에서 신발을 신은 발과 양말만 신은 발을 구별할 수 있었다. 별도 돌발 `special_005`도 자동문 그림 → 이미지 터치 → 본문 순으로 확인했다.
- **정원률 검수 완료 (2026-11-16), 판정 통과.** 확인한 화면에서 자동 카드와 돌발 그림은 뒤섞이지 않았다. #79 목록 49건 전부 표시할 `momentImageId`가 비어 있다. 카페 샘플은 §11의 검수용 상태이며, 사건 그림 연결 화면은 사용 결정 뒤 확인할 수 있다.
