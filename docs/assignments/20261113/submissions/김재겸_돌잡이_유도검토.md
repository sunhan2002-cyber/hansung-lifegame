# 돌잡이 컷신 그림의 선택 유도 검토 (2026-11-16, 김재겸)

과제: "선택 전 돌잡이 이미지가 특정 선택을 부당하게 유도하는지 확인하고 결과를 문서화한다."

## 결론

**유도가 있다.**
- **보이는 것**: 선택 바로 앞 컷신 그림이 아기 손이 **판사봉(B)을 잡은 순간**을 보여 준다. 플레이어가 고르기 전에, 정답처럼 보이는 그림을 먼저 보게 된다.
- **능력치 불공정은 작다**: B는 세 선택지 중 보상이 가장 큰 쪽이 아니다.
  - 그림은 쏠림을 만들지만, B를 골라도 능력치에서 큰 이득은 없다.
- **이야기가 어긋난다**: 피아노(A)나 5만 원권(C)을 고르면, 방금 본 그림과 결과 문장 · 뒤이은 돌잡이 사진이 맞지 않는다(세 갈래 중 두 갈래).

이번에 바꾼 것과 바꾸지 않은 것:
- **고친 것: 컷신 그림의 화면 낭독 문구**
  - 전에는 "아기 손이 그중 하나로 뻗는다"로, 승인 전 그림 기준 문장이었다.
  - 이 때문에 화면 낭독 사용자만 그림과 다른 장면을 들었다.
  - 정원률 manifest의 `accessibilityDescription`과 같은 문장으로 바꿨다.
- **바꾸지 않은 것**: 그림 · 컷신 순서 · 승인 manifest · SHA.
  - 통합지시서(11/13)가 "아기의 손이 한 물건을 잡는 구도"로 확정했으므로, 바꿀지는 팀장 결정으로 남긴다.
