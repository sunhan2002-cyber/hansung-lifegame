# 정원률 과제: UI·이미지·돌잡이 장면

## 담당 범위

1. 돌잡이 장면을 신규 이미지로 제작한다.
   - 탁자 위에 여러 물건 배치
   - 아기의 손이 한 물건을 잡는 순간
   - 엄마가 물건을 건네는 단순 구도 금지
   - 기존 화풍·시점 규칙과 안전 크롭 범위를 유지
2. 자동 소사건에 필요한 이미지가 있는지 신기훈의 콘텐츠 목록과 대조한다.
3. 승인된 이미지의 SHA-256을 바꾸지 않는다.
4. 새 이미지가 필요하면 먼저 의미·화풍·크롭 검수용 샘플을 제출하고 승인 후 본 제작한다.
5. 캐릭터 커스터마이징 UI의 색상·간격·선택 상태를 검수한다.
6. 주사위 화면에서 눈금, 계산식, 합계, 최종 스탯이 한눈에 읽히는지 확인한다.
7. 사건 이미지 선노출이 전체 화면에 맞고, 검은 띠·잘림·무관한 이미지가 없는지 확인한다.
8. 이미지 크롭과 승인 PNG 압축 정책은 품질·용량·SHA 영향 비교표를 작성해 AI 판단 근거로 제출한다.

## 필수 검수

- 돌잡이 이미지가 여러 물건과 아기 손을 실제로 포함하는지
- 1080×2400 및 작은 화면에서 핵심 사물이 크롭되지 않는지
- 자동 사건 이미지와 돌발 사건 이미지가 서로 뒤바뀌지 않는지
- 승인 manifest의 원본 SHA와 현재 승인 파일이 일치하는지
