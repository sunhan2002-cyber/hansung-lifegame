# 김우영 과제: 게임 로직·상태·자동 진행

## 담당 범위

1. 최신 main과 PR #73을 기준으로 다음 시연 전 결함을 수정한다.
   - 노년기 건강 이중 감소
   - 건강 0 즉시 사망 규칙 통일
   - 결과 화면 시기·연도 스냅샷 보존을 위한 도메인 상태 제공
   - 저장 후 새 사실 변화 보존
   - 재직·실직·은퇴 플래그 배타성
2. 자동 소사건 시스템을 구현한다.
   - 매년 카운터를 새로 도입하지 않는다.
   - 일정 시간 경과 또는 게임 진행 단계 변경을 트리거로 자동 사건 후보를 선택한다.
   - 스탯이 바뀔 만한 사건에만 스탯 효과를 적용하고 나머지는 기록만 남긴다.
   - 중복 실행 방지와 저장·복원
   - 돌발 사건·전환점보다 선택 사건을 우선하지 않도록 우선순위 보장
3. 돌잡이 컷신 상태를 새 게임·복원·건너뛰기 후에도 안정적으로 관리한다.
4. 주사위 계산 모델을 확정한다.
   - 두 눈의 합을 사용한다. 예: `1 + 3 = 4`
   - 보정 전 눈값, 합계, 최종 스탯을 상태와 로그에 보존

## 필수 테스트

- 노년기 사건 있음/없음에서 연간 건강 감소가 정확히 한 번만 적용되는지
- 건강 0이 어느 경로에서도 생존하지 않는지
- 자동 사건이 같은 턴에 중복 실행되지 않는지
- 자동 사건 후 돌발 사건이 정상적으로 이어지는지
- 앱 재실행 후 주사위 결과·자동 사건·사실 변화가 복원되는지
- 주사위 화면의 표시 합계와 실제 초기 스탯이 일치하는지
