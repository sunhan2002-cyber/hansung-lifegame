# 김재겸 과제: 화면 흐름·시연 조작·커스터마이징

## 담당 범위

1. PR #73을 main 기준으로 재검토하고 병합 가능한 상태인지 확인한다.
2. 돌발 사건 화면 순서를 고정한다.
   - 장면 이미지 선노출
   - 사건 제목·본문 타이핑
   - 선택지 표시
3. 선노출이 터치·시간 초과·뒤로가기로 끝날 때 터치가 선택지로 통과하지 않도록 한다.
4. 결과 화면에 선택 당시 시기·연도·이미지·사실 변화가 표시되도록 UI를 연결한다.
5. 돌잡이 컷신이 새 게임 시작에서 보이고, 건너뛰기·완료·복원이 정상 동작하는지 수정한다.
6. 캐릭터 선택 화면에 외형 커스터마이징 UI를 추가한다.
   - 헤어·색상·얼굴·의상·사진 기반 선택을 모두 검토하고, 구현 불가능한 항목은 제한 사유를 기록한다.
   - 선택값 저장·복원
   - 작은 화면과 큰 글씨에서 잘림 없음
7. 선택지 라벨의 불필요한 마침표를 제거한다.
