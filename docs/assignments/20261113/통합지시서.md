# 11주차 후속 통합 과제

기준 브랜치: 최신 `main`  
목표: 재겸이의 main 전체 검토 결과와 신규 요구사항을 반영해 시연 흐름과 인생 개연성을 보완한다.

## 공통 규칙

- 각자 `feat/week11-<name>-<topic>` 브랜치에서 작업한다.
- 개인 브랜치에서 테스트와 검증을 마친 뒤 PR을 만든다.
- `main` 직접 푸시와 강제 푸시는 금지한다.
- 기존 저장 버전과 이전 선택 기록을 깨뜨리지 않는다.
- 승인 이미지의 SHA-256을 임의로 갱신하지 않는다.
- `local.properties`, API 키, 원본 사진, 영상·스크린샷은 커밋하지 않는다.
- 문서에는 실제 구현·검증된 내용과 미구현 계획을 구분해 적는다.

## 선행 순서

1. 김재겸 PR #73 변경을 리뷰하고 병합한다.
2. 김우영이 건강·결과 스냅샷·플래그 상태를 수정한다.
3. 신기훈이 자동 소사건·러브라인·직업 개연성 콘텐츠를 반영한다.
4. 김재겸과 정원률이 화면·이미지·돌잡이 연출을 반영한다.
5. 김선한이 통합 QA와 APK·에뮬레이터 검증을 수행한다.

## 신규 기능 요구사항

### 자동 진행 소사건

각 시기에 짧은 자동 진행 사건을 둔다. 예시는 감기, 친구와 싸움, 연애 시작, 부모님께 용돈 받기다. 자동 사건은 선택지를 요구하지 않고 시간 흐름 중 표시되며, 스탯에 영향을 주거나 영향 없이 기록만 남길 수 있다.

- 시기별 최소 5개 이상 후보를 조사한다.
- 사건마다 `eventId`, 시기, 본문, 이미지 사용 여부, 스탯 변화, 사실/플래그, 중복 규칙을 명시한다.
- 자동 사건이 돌발 사건·인생의 전환점보다 우선해 선택을 가로채지 않게 한다.
- 기록 화면과 인생 요약에 자동 사건을 구분해 남긴다.

### 돌발 사건 표시 순서

돌발 사건은 `장면 이미지 선노출 → 사건 제목·본문 → 선택지` 순서로 표시한다. 이미지 로딩 실패 시 선노출 완료로 저장하지 않으며, 타이핑·시간 초과·뒤로가기 종료 직후 터치가 선택지로 통과하지 않아야 한다.

### 돌잡이 컷신

게임 시작 시 돌잡이 컷신이 실제로 표시되어야 한다. 화면 진입, 저장·복원, 건너뛰기, 완료 후 첫 사건 이동을 검증한다. 돌잡이 장면은 여러 물건이 놓인 상 위에서 아기의 손이 한 물건을 잡는 구도여야 한다.

### 주사위 초기 능력치

주사위 눈과 초기 스탯 계산의 관계를 사용자에게 명확히 보여준다. 예를 들어 두 눈을 굴리면 `1 + 3 = 4`처럼 합계 또는 사전에 정한 계산식을 화면에 표시하고, 결과 스탯에 같은 값이 반영되어야 한다. 음수 보정이 있다면 보정 전·후 값을 함께 표시한다.

### 커스터마이징

캐릭터 선택에서 기본 캐릭터 외에 가능한 범위의 외형 선택을 제공한다. 선택값은 새 게임 시작 상태와 저장·복원에 유지되어야 한다.

### 선택지 문장 정리

선택지 라벨의 불필요한 마침표를 제거한다. 예: `수능을 본다.` → `수능을 본다`. 본문과 결과 문장의 마침표는 문장 규칙에 따라 유지한다.

### 러브라인·가족 개연성

연애 시작 → 관계 진행 → 갈등 또는 안정 → 결혼 결정 → 결혼식 → 자녀 계획·출산 순서의 사건을 추가한다. 갑자기 결혼·출산 상태가 생기지 않도록 선행 플래그와 사건 기록을 연결한다.

## 공통 완료 기준

- Debug/Release 단위 테스트 통과
- 콘텐츠 검증 통과
- 관련 기기 테스트 추가 또는 갱신
- 자동 소사건이 각 시기에서 실제로 표시됨
- 돌잡이 컷신이 새 게임에서 표시됨
- 돌발 사건 순서가 이미지 → 본문 → 선택지로 유지됨
- 주사위 계산식과 결과 스탯이 화면에서 설명 가능함
- 러브라인·결혼·자녀 사건이 플래그 순서대로 진행됨
- 기존 저장 복원과 결말 흐름이 깨지지 않음
- PR 설명에 테스트 명령과 결과를 기록함

## 팀장 확정이 필요한 정책

아래 항목은 코드 담당자가 임의로 확정하지 않고, 팀장이 회의에서 결정한 뒤 과제에 반영한다.

| 결정 항목 | 선택지 | 현재 과제의 기본 제안 |
|---|---|---|
| 건강 0 처리 | 즉시 사망 / 확률 판정 | 건강 0은 모든 경로에서 즉시 사망 |
| `lifeDelta` 정책 | 삭제 / 건강 변화에 합산 / 별도 생명력으로 유지 | 생명력은 폐지하고 건강 변화로 통합. 부상 결과는 최종 건강이 음수여야 함 |
| 주사위 계산 | 두 눈 합계 / 차이 / 다른 고정식 | 합계 표시. 예: `1 + 3 = 4`, 보정이 있으면 보정 전·후를 함께 표시 |
| 자동 소사건 빈도 | 매년 1건 / 시기당 여러 후보 중 일부 / 확률 발생 | 시기마다 후보를 두고 한 진행 단위에 최대 1건, 돌발 사건과 중복 금지 |
| 자동 소사건 영향 | 스탯 필수 / 기록만 허용 | 둘 다 허용하되 JSON에 영향 여부를 명시 |
| 러브라인 범위 | 단일 선형 경로 / 여러 분기 | 최소한 만남→연애→결혼 논의→결혼식→자녀의 순서를 보장하고 분기는 선택적으로 추가 |
| 커스터마이징 범위 | 색상·헤어 / 얼굴·의상 / 사진 기반 얼굴 | 현재 자산과 저장 구조가 감당하는 범위만 구현하고, 사진 원본은 커밋하지 않음 |
| 돌잡이 이미지 승인 | 기존 이미지 수정 / 신규 이미지 제작 | 신규 또는 수정 PNG는 의미·화풍·크롭 검수 후 연결 |
| 시연 APK | Debug / 서명된 Release | 개발용 버튼이 없는 서명 APK 우선. 불가능하면 Debug 시연 사실을 회의에서 고지 |
| 이미지 크롭 | 중앙 크롭 / 전체 보기 선택 제공 | 기본 중앙 크롭 유지. 핵심 사물이 잘리면 제작자가 안전 영역을 수정 |
| 승인 이미지 압축 | 원본 유지 / 압축본 승인 갱신 | 승인 SHA는 유지하고, 승인 전 이미지만 최적화 가능 |

결정이 끝나면 김선한이 이 표의 “현재 과제의 기본 제안”을 회의 결정으로 갱신하고, 김우영·신기훈·정원률·김재겸은 그 결정만 구현한다.
