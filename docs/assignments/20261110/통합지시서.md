작성일: 2026-11-10  
기준: 최신 `main`과 최신 개인 제출 브랜치

## 목표

현재 사건은 352개, 고유 이미지 그룹은 351개다. 승인 완료는 15그룹·16사건이며, coverage 기준 승인 대기 사건은 336건이다. 이번 과제의 목표는 이 336건을 담당자별로 전수 확인하고, 실제 PNG·의미 검수·화풍 검수·중앙 크롭·앱 라우팅을 모두 완료하는 것이다.

PNG가 존재하는 것, 개인 자체 검수를 통과한 것, 팀 최종 승인, 앱에서 실제로 표시되는 것은 서로 다른 상태다. 상태를 숫자만 줄여 완료 처리하지 않는다.

## 그룹별 완료 조건

각 그룹은 아래 조건을 모두 채워야 `APPROVED`로 전환한다.

1. 사건 ID·그룹 ID·PNG 경로가 일치한다.
2. PNG가 실제 파일이고 4:3 원본이며 SHA-256을 기록한다.
3. 사건 본문의 행동·필수 사물·인물/시점·시기가 이미지에 맞는다.
4. 선택 결과를 미리 보여주거나 본문에 없는 결말을 그리지 않는다.
5. 휴대폰 세로 중앙 크롭에서 핵심 사물이 남는다.
6. 도트풍·색감·품질 기준을 통과한다.
7. `image_routing.json`과 승인 manifest에 연결된다.
8. 실제 앱 장면 보기에서 해당 PNG가 표시되는 것을 확인한다.

## 제출물

각자 개인 브랜치와 PR로 다음을 제출한다.

- 실제 PNG 또는 수정 PNG
- 그룹 ID·사건 ID·경로·원본 크기·SHA-256 manifest
- 의미 검수표
- 크롭 검수표와 캡처 또는 재현 로그
- 화풍 검수 결과
- 라우팅 변경 내역
- 실행한 테스트 명령과 결과
- 통과하지 못한 항목은 `PENDING`으로 남긴 미완료 목록

## 최종 인수 게이트

김선한은 5명 PR을 통합한 뒤 다음을 다시 실행한다.

- `python scripts/validate_content.py`
- `python scripts/validate_images.py`
- `python scripts/validate_followup_image_coverage.py`
- Python 회귀 테스트
- Debug·Release 테스트와 APK 빌드
- 에뮬레이터에서 시작→컷신→이미지 선노출→선택지→결과→저장/복원

`pendingEvents=0`, 승인 manifest와 routing 일치, 위 테스트 통과, 실기기 흐름 확인 전에는 개발 최종 완료로 표시하지 않는다.
