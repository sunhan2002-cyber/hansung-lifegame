# PR #82 | APK 크기와 실행 성능 검증

## APK 재측정

11월 20일 로컬에서 main `d133bb4`의 시연용 Debug APK와 PR #82 `797e939`의 APK를 비교했다. PR 후보의 `:app:assembleDebug`와 `:app:assembleRelease`는 성공했다. APK 파일 전체의 바이트를 잰 뒤 내부 ZIP 항목을 경로별로 합산했다.

| 비교 대상 | 파일 바이트 | MiB |
| --- | ---: | ---: |
| main `d133bb4` Debug | 254,462,135 | 242.67 |
| PR #82 `797e939` Debug | 500,068,890 | 476.90 |
| PR #82 `797e939` 미서명 Release | 496,425,280 | 473.43 |

Debug끼리 비교하면 **245,606,755바이트(234.23MiB, 96.52%) 증가**했다. PR 디버그에 추가된 세로 파생 PNG 95장은 **218,632,316바이트(208.50MiB)**로 전체 증가량의 약 89%다. 나머지 그림 에셋 ZIP 항목도 36.24MiB 늘었다. 이 값은 APK 파일 크기다. 설치 후 저장 공간이나 다운로드 분할 패키지 크기를 뜻하지 않는다.

첨부 검증 기록의 `230.39 → 479.21MiB`는 이전 기준 `e08d25f`와 당시 후보의 비교이고, 위 표는 최신 돌잡이 원화가 포함된 `d133bb4`와 `797e939` 비교다. [11월 19일 측정 기록](https://github.com/sunhan2002-cyber/hansung-lifegame/blob/797e939/docs/refactor/20261119-emulator-results.md)

## 실행 성능 측정 조건

- 같은 API 36 에뮬레이터(1080×2400, RTX 3050 Ti 호스트 그래픽)에서 두 Debug APK를 차례로 설치했다. 시험용 에뮬레이터는 별도로 열었다.
- 각 APK에서 앱 프로세스를 종료하고 다시 여는 콜드 실행을 3회 반복했다. 첫 화면까지 걸린 시간은 `ActivityTaskManager`의 `Displayed` 로그에서 읽었다. 별도로 실행 명령 후 5초 대기하고 `dumpsys gfxinfo`를 초기화한 뒤 15초 동안 프레임을 수집했다. 첫 화면이 뜨기 전에 시작한 구간의 프레임 값은 성능 판정에 쓰지 않는다.
- 소프트웨어 렌더링 시험에서는 시스템 UI 응답 지연과 시작 제한 시간 초과가 발생했다. 그 표본은 호스트 그래픽 시험과 합산하지 않았다.

| Debug APK | 첫 화면 표시 3회 | 중앙값 |
| --- | --- | ---: |
| main `d133bb4` | 30.810초 / 26.017초 / 11.161초 | 26.017초 |
| PR #82 `797e939` | 12.936초 / 5.949초 / 4.957초 | 5.949초 |

main 2회와 PR 1회는 `am start -W`의 제한 시간을 넘겼지만 첫 화면 표시가 끝난 시점은 시스템 로그에 기록됐다. 한 에뮬레이터에서 main을 먼저 측정했고 초반 시스템 부하와 회차별 편차가 컸다. 이 수치로 시작 성능의 개선 폭을 확정하기에는 표본과 환경 통제가 부족하다.

| PR #82 로비 | 수집 프레임 | 지연 프레임 | 프레임 95백분위 | 앱 PSS |
| --- | ---: | ---: | ---: | ---: |
| 1회 | 844 | 67 (7.94%) | 48ms | 97.63MiB |
| 2회 | 865 | 34 (3.93%) | 46ms | 101.69MiB |
| 3회 | 914 | 12 (1.31%) | 40ms | 110.18MiB |

PR 로비의 모션 기본값에서 95백분위 40~48ms를 관찰했다. 이 값은 60Hz 화면의 한 프레임 예산인 16.7ms를 넘는다. main의 첫 두 프레임 수집은 화면 표시가 끝나기 전에 시작했고, 세 번째의 고정 화면은 수집 구간에 새 프레임이 0개였다. main과 PR의 프레임 95백분위를 직접 비교할 표본은 없다.

이번 재측정 범위는 첫 화면과 로비다. 주사위·대표 장면과 모션 끄기 비교, 실기기 발열·배터리, 서명 Release 실행 측정은 통합 후보 인수 절차에 포함한다. [통합지시서](통합지시서.md)

용량은 세로 파생본부터 개선한다. 작은 화면에서 얼굴·핵심 사물이 읽히는 크기로 해상도를 낮추고, 전체 화면 크롭으로 충분한 장면은 원본의 초점을 조정할 수 있다. 변경한 파생본은 화면 비교와 파일 해시 검사 후 전후 용량을 기록한다.
