## 통합 후보

원격 `main` `20333a8`에서 통합 브랜치를 만들었다. [PR #82](https://github.com/sunhan2002-cyber/hansung-lifegame/pull/82) `1b8169e`를 포함한 [PR #85](https://github.com/sunhan2002-cyber/hansung-lifegame/pull/85) `1f3f2df`와 [PR #83](https://github.com/sunhan2002-cyber/hansung-lifegame/pull/83) `a009652`, [PR #84](https://github.com/sunhan2002-cyber/hansung-lifegame/pull/84) `f8914d1`, [PR #86](https://github.com/sunhan2002-cyber/hansung-lifegame/pull/86) `a6ca862`를 합쳤다.

- 여섯 주사위 결과 행이 게임 로직의 단일 결과를 사용한다. 시작·저장 뒤 도전 코드를 다시 공유할 때도 LG1의 계산 버전을 유지한다.
- 리셋 확인은 기존 저장 계층의 비동기 디스크 확인과 실패 복구를 사용한다. 사용 경로와 분리돼 있던 동기 삭제 구현을 통합 과정에서 정리했다.
- 신기훈의 본식 네 사건 ID를 공통으로 사용한다. 본식은 교제·약혼·양가 인사·준비·단일 상대가 갖춰졌을 때 열리고, 준비와 본식은 기록 화면에서도 구분된다.
- 예전 저장이 본식 선택을 기다리고 있으면 현재 조건을 다시 확인한다. 준비가 가능한 인생은 준비 사건으로 이어지고, 이미 혼인을 마친 인생은 이전 결과를 복제하지 않는다. 같은 진행 구간의 초점 보상도 다시 적용하지 않는다.
- 김우영의 상대·배우자 고유 ID 계약을 연결하면서 PR #82의 재직 상태 갱신 규칙을 유지했다. 재굴림 버튼은 3D 주사위 바로 아래에 배치해 작은 화면에서 두 요소를 함께 볼 수 있게 했다.
