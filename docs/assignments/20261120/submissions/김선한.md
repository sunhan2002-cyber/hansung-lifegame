- 김우영의 상대·배우자 고유 ID 계약을 연결하면서 PR #82의 재직 상태 갱신 규칙을 유지했다. 재굴림 버튼은 3D 주사위 바로 아래에 배치해 작은 화면에서 두 요소를 함께 볼 수 있게 했다.

### 에뮬레이터 성능 비교

Android API 36, 1080×2400, RTX 3050 Ti 호스트 그래픽 가속을 사용했다. 전용 기기에 PR #82 Debug `797e939`과 통합 Debug를 차례로 설치했다. 로비 콜드 런은 각 3회, 표의 개별 장면은 모션 상태마다 1회다. 첫 Activity 표시를 `am start -W`로 기록하고, 3초 대기 뒤 `gfxinfo`를 초기화해 5초 구간의 프레임과 메모리를 수집했다. Activity 표시는 실제 이미지 디코딩 완료 시간과 다를 수 있다.

| 모션 켜짐 | PR #82 첫 표시 | 통합 첫 표시 | PR #82 P95 / 지연 프레임 | 통합 P95 / 지연 프레임 | PSS 전 → 후 |
| --- | ---: | ---: | --- | --- | ---: |
| 로비 콜드 런 3회 | 중앙값 8,496ms | 중앙값 3,665ms | 34~61ms / 0.94~13.87% | 31~34ms / 0.33~1.32% | 85.8~97.0 → 97.6~108.4MiB |
| 로비 미리보기 | 9,097ms | 2,715ms | 48ms / 15÷304 | 32ms / 3÷301 | 82.8 → 102.4MiB |
| `teen_024` | 6,983ms | 3,065ms | 프레임 표본 0 | 46ms / 6÷300 | 87.8 → 103.8MiB |

통합 후보에서 모션을 끄면 위 로비 미리보기와 대표 사건의 안정 구간에 새 프레임이 0개였다. 통합 후보의 주사위 미리보기는 모션 켜짐·꺼짐의 첫 표시가 각각 2,209ms·1,920ms, PSS가 85.5·84.9MiB였다. Native 3D Surface의 프레임 시간은 이 `gfxinfo` 측정에서 추정하지 않았다. 실행 순서에 따라 운영체제 예열 상태가 달랐고 장면별 표본이 적어 성능 개선 폭을 확정하려면 반복 측정이 필요하다. 물리 기기에서의 발열·배터리와 팀 키 서명 릴리스 검증은 대기다.
