## 3. 승인 이력과 검수 상태

2026-11-22 사용자가 원본 시안 11장에 이어 최종 실제 장면 보기 11장도 승인했다. 실제 앱 화면의 AI 검수 결과는 상세 기록의 `nativeReview`에 크기별 캡처 SHA와 함께 남겼다. 사용자는 제시한 장면 보기 크롭을 확인했으며 전체 인생 분기 E2E를 직접 검수했다고 확대하지 않는다. 팀 최종 인수는 별도다.

교체된 기존 `love_wedding_01`, `love_wedding_music`의 승인 그룹 2개는 상세 기록의 `previousApprovals`에 원문 그대로 보존했다. 종전 PNG와 검수 증거 파일도 보존했다. 최종 사용자 장면 검수와 AI의 현재 사건·결과·실제 캡처 검토 후, 새 11장과 중립 돌잡이는 현재 PNG SHA를 가리키는 별도 AI 인수 그룹으로 등록했다. 이전 파일의 승인을 그대로 승계하지 않았고, AI 인수를 팀 최종 사람 승인으로 표시하지 않았다.

## 6. 돌잡이 중립 장면 승인 및 선택 전후 분리

아래 작업 경과의 대기·미반영 표시는 각 작업 시점의 기록이다. 현재 완료 상태는 문서 상단과 마지막 절을 기준으로 한다.

기존 판사봉 원화의 화풍과 가족·상 배치를 참고해 아기 손·소매를 지우고, 피아노 장난감·판사봉과 받침·지폐를 중앙에 모은 시안을 제작했다. 어떤 물건도 잡거나 강조하지 않은 선택 전 장면이다. 1080×2400 중앙 크롭에서도 세 물건 전체가 보이는 것을 AI가 확인했다.

사용자가 2026-11-22 시안을 승인해 원본 PNG를 바이트 그대로 `followup_20261120/img_infant_toys_001.png`에 연결했다(1448×1086, SHA-256은 상세 기록 참조). 이전 중립·판사봉 원본과 기존 사건용 복사본은 보존했다.

선택 전 컷신·선택 화면·장면 보기는 중립 그림이다. B(판사봉)를 실제 선택한 결과에서만 기존 `cutscenes/week11/img_doljabi_grasp_001.png`를 사용하며, A(피아노)와 C(지폐)는 중립 그림을 유지한다. 컷신 화면 낭독 문구도 중립 장면과 일치시켰다.

결과 이미지 ID를 선택 기록과 저장된 결과에 함께 기록한다. 이어하기와 주마등은 `infant_007`의 실제 선택 ID를 기준으로 그림을 복원하므로, 예전 저장의 그림 ID가 없거나 공통 그림으로 남아 있어도 B는 판사봉, A/C는 중립 그림이다. 다른 사건의 저장된 결과 그림은 기존 처리대로 유지한다. 게임 보상·시나리오·저장 형식은 변경하지 않았다.

PNG의 기존 필터와 이미지 데이터를 유지하고 zlib 압축 전략·메모리 설정을 비교했다. 원본 파일에 종속된 `caBX` 출처 서명 청크는 파생 시험본에 승계하지 않고, 출처 기록을 가진 원본은 그대로 보존했다. 그 외 PNG 청크는 보존했다. 원본/시험본 SHA, IDAT별 절감량과 메타데이터 제외량은 시험 보고서에 구분했다.

시험본 5장, `report.json`, 픽셀 검증 스크립트, 구성 미리보기는 저장소 밖 `portrait-compression-sample-20261122`에 두었다. 사용자 검수 전 시험 결과이며 나머지 90장은 처리하지 않았다.
