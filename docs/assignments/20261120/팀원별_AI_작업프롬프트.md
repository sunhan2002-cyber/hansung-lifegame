# 11월 20일 | 담당별로 AI에게 전달할 메시지

## 김선한 · 통합·QA

> [통합지시서](통합지시서.md)와 [APK·성능 재검증](APK_성능_검증.md), PR #82를 확인해 통합 후보를 만들어 줘. 팀원 변경을 원격 main과 대조하고, AI 검수 커밋 `cb4c9ff` 및 `infant_007`의 현 파일·라우팅·원본/파생 SHA와 검수 근거를 점검해. 사람 검수와 AI 검수 표기는 구분해. 같은 기기에서 APK 실제 바이트, 시작·장면 로딩, 프레임 P95·지연률, 메모리를 비교하고 실기기 발열·배터리는 측정한 환경과 함께 보고해. 고정 시드로 1+4→+5→55와 레거시 도전 코드, 리셋 취소/확인 및 실패 복구, 3개 연애 루트의 실제 본식, 거절·비혼, 6시기의 표시 문구·사망 시기를 검증해. 전체 Android 계측·시뮬레이션·콘텐츠 엄격 인수·릴리스 보안·원격 CI 결과와 서명 여부를 `submissions/김선한.md`에 적고 통합 결과를 확인해.

## 김우영 · 게임 로직

> [통합지시서](통합지시서.md)의 주사위·리셋·결혼 규칙을 구현해 줘. 신 규칙에서는 각 능력치의 두 눈 합이 실제 증가량이야. 1+3은 +4로 최종 54, 1+4는 +5로 최종 55야. 6개 능력치의 눈·합·증가량·최종값을 단일 결과 객체로 UI에 넘겨. 기존 LG1은 이전 수치로 재현하고 새 코드 버전을 구분해. 저장된 실제 능력치·건강 시작값·재굴림 횟수를 보존하고 앱과 시뮬레이터 시작 경로를 함께 검증해. 진행 중 리셋은 현재 진행·타이머만 정리하고 저장 실패·연타·앱 재실행에 견디게 해. 신기훈과 합의한 상대 ID 및 교제/약혼/양가/본식 조건으로 혼인을 한 번만 확정하고 이미 결혼한 저장을 보존해. 36쌍×6개 능력치, 구·신 저장과 도전 코드, 최초 본식 보상, 리셋의 성공/실패를 확인해 `submissions/김우영.md`에 남겨.

## 김재겸 · 프론트엔드

> [통합지시서](통합지시서.md)를 기준으로 PR #82 후속 UI를 작업해 줘. 주사위는 화면에 보이는 3D 눈이 어느 능력치인지 이름을 붙이고, 여섯 능력치 줄 각각에 해당 눈과 합, 실제 증가량, 최종값을 연결해. 예시는 ‘경제력 · 1 + 4 = 5 · 50 + 5 = 55’야. 로직 값을 사용하고 정적 대체와 읽기 지원에도 같은 값을 줘. 진행 화면에서 ‘인생 리셋’을 눌렀을 때 경고·취소·새 인생 시작을 제공하고 취소 시 원래 화면으로 돌아가게 해. ‘영아기 · 다음 사건을 기다리는 중’, ‘영아기 · 1번째 해’, ‘다음 해까지’, ‘그해 이야기’ 같은 반복 문구를 정리해. 하단 시기 바와 배속·다음 결정 기능은 유지해. 연애·본식 사건과 기록 화면에서 같은 상대와 본식 결과를 확인할 수 있게 하고, 마지막은 360×640dp 글꼴 200%, 3D 대체·복원·리셋 연타, 모션 켬/끔 성능 전후로 검증해 `submissions/김재겸.md`에 남겨.

## 신기훈 · 시나리오

> [통합지시서](통합지시서.md)를 읽고 현재 러브라인 사건 20건과 기존 상대별 분기를 파악해 줘. 최소 세 인연이 선택 가능한 실제 만남과 교제로 시작하고, 각각 다른 첫 데이트 및 추가 사건을 거쳐 결혼 논의·양가 인사·준비·플레이어 본인의 실제 본식까지 이어지게 작성해. 결혼식 10분 전과 음악 축가를 재사용하더라도 독립 본식에서 입장·서약·축하와 실제 선택 결과가 있어야 해. 상대 정체성, 선행 사건 ID, 플래그, 해제 조건, 기존 저장 호환을 우영이와 먼저 맞춰. 기존 ‘결혼한다’ 문구가 약혼으로 저장되는 지점도 정리해. 거절·결별·보류·비혼이 가능한지 고정 시드로 확인하고, 원률이에게 사건 ID·장소·등장인물·필수 사물 명세를 먼저 줘. 분기표·JSON·검증 결과를 `submissions/신기훈.md`에 남겨.

## 정원률 · UI·이미지

> [통합지시서](통합지시서.md)와 [APK·성능 재검증](APK_성능_검증.md)을 읽고 신기훈의 사건 ID·장면표를 기준으로 실제 결혼식 본식, 준비, 상대별 주요 연애 장면의 전용 PNG를 제작하고 앱 경로에 연결해 줘. 기존 러브라인 전용 PNG 20장은 중복 제작량으로 세지 마. 돌잡이 선택 전에는 세 물건이 중립적으로 보이는 그림을 검수하고 판사봉을 잡는 그림은 그 선택 결과가 확정되는 지점에 연결하도록 프론트와 협업해. 현재 95개 세로 파생본의 알맞은 해상도와 압축을 비교해. 작은 화면에서 핵심 사물·인물 식별과 도트 경계를 확인하고 원본과 실제 표시 PNG의 경로·SHA·검수 사유·바이트 절감치를 각각 적어. 이미 승인된 원본과 파생본이 바뀌면 해시에 맞춰 검수 기록을 갱신하고 `submissions/정원률.md`에 남겨.
