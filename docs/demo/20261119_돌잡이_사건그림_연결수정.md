# 돌잡이 선택 화면의 신규 그림 연결

- 사용자 화면에서 `infant_007` 돌잡이에 보호자가 치발기를 건네는 기존 그림이 표시됨을 확인했다.
- 원인: 컷신은 `cutscenes/week11/img_doljabi_grasp_001.png`를 직접 사용하지만 사건용 ID `img_infant_toys_001`은 `followup_20261031/img_infant_toys_001.png`를 가리켰다. 신규 PNG의 부재가 아니라 사건 라우팅 누락이다.
- 사건 ID와 기존 저장의 이미지 ID를 유지하고 해당 ID의 라우팅을 새 돌잡이 PNG로 바꿨다. 새 게임·진행 중 저장 복원·기록 화면 모두 같은 ID로 신규 그림을 읽는다.
- 사건 ID와 PNG 파일명이 같아야 하는 콘텐츠 계약을 지키기 위해 신규 원본을 `cutscenes/week11/events/img_infant_toys_001.png`로 바이트 동일 복사했다. 카탈로그 해상도는 실제 1448×1086으로 맞췄다.
- `ImageRoutingTest`에 실제 사건 파싱 → 선택 화면 / 저장 복원 화면 → 신규 PNG 경로 확인 회귀 검증을 추가했다.
- 신규 PNG의 바이트·기존 컷신 연결은 변경하지 않았다. 그림이 판사봉을 잡는 모습을 보여 주는 선택 유도 문제는 기존 검토 기록대로 남는다. 이번 수정으로 최종 그림 승인이 새로 완료됐다고 처리하지 않는다.
- 이전 직접 그림 검수표의 `infant_007` 판정은 수정 전 치발기 PNG SHA에 대한 기록이다. 이번 경로 변경은 이 문서를 최신 근거로 삼는다.
