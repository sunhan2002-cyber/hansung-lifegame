1. 지난주 대비 달라진 플레이

항목지난주 main · 11월 12일오늘 통합본시연에서 볼 부분
자동 소사건현재의 자동 소사건 JSON·화면 연결이 없음감기·용돈·다툼 등 시기별 49개 후보를 조건에 따라 선택. 스탯 변화가 있는 사건과 기록만 남는 사건을 구분자동 진행 화면 위쪽의 ‘자동’ 카드, 변화 수치 또는 기록 전용 안내
이야기 연결선택 결과와 후속 기억을 연결하는 확장 콘텐츠가 없음실제 선택을 근거로 ‘그때 그 선택’ 회상과 인생의 계기 카드를 조회. 기존 기록·관계 조건에 맞는 인물 재등장돌잡이 선택 뒤의 자동 이야기, 결말의 계기·회상 영역
러브라인기존 사건 목록 352건데이트·갈등·재회·양가 인사·결혼식·아이 계획 등 20건 추가. 선행 관계·결혼·가족 조건을 검증조건을 충족한 인생에서 후속 사건이 자연스럽게 이어지는지 확인
새 인생 시작현재 돌잡이 컷신 화면과 연결 흐름이 없음프로필 → 시작 → 돌잡이 컷신 → 첫 선택 사건. 완료·건너뛰기 상태를 저장컷신 자동 종료, 건너뛰기, 이어하기에서 중복 재생 여부
주사위·도전 코드현재의 출발선 코드와 합계 기반 표시 흐름이 없음두 눈·합계·보정·최종 스탯 표시. 성별·시드·주사위를 담은 도전 코드 생성·복사·적용코드를 적용한 직후 숫자가 다시 섞이지 않고 바로 일치하는지
캐릭터 설정기존 외형 선택 구성머리·의상 색상 및 얼굴/사진 관련 화면·안내 확장. 선택값 저장·복원색상 변경 → 미리보기 → 게임 시작 → 이어하기
사건 화면 순서기존 선노출·뒤로가기 오류 수정까지 반영된 상태새 사건 화면 흐름 통합. 돌발 안내 → 사건 보기 → 이미지 선노출 → 본문·선택지, 타이핑 중 터치로 전문 표시이미지를 넘기는 터치가 아래 선택지까지 누르지 않는지
건강·사망일부 시기의 건강 하한과 노년기 감소 중복 문제가 남음건강 0 즉시 사망 규칙 통일. 노년기 감소 중복 제거. 실제 사망 시기 보존건강이 0이 된 시점의 결말·사망 시기
결과·저장결과 시점과 복원 상태 불일치 가능성선택 당시 시기·진행 위치, 결과의 새 사실·확장 상태를 저장. 자동 사건 보상·기록 중복 차단결과 화면에서 앱 재실행 → 이어하기 → 같은 결과·스탯 확인
직업 상태재직·실직·은퇴 상태 정합성 보완 필요새 직업 상태가 생기면 이전 상태를 정리. 직업과 무관한 선택·자동 사건은 기존 재직 상태를 유지하도록 추가 수정취업 뒤 일상 선택을 해도 직업이 유지되는지
칭호 목표현재의 목표·힌트 확장 없음칭호 수집 화면에서 힌트 확인과 ‘다음 판에서 노리기’ 저장목표 지정 후 새 인생 화면에서 확인

기록 기반 확장실제 기록만 회상·계기·NPC 조회에 사용하도록 두 구현의 계약을 맞춤. NPC 재등장 정의 9 → 16개
콘텐츠 조건 감사전환점 선택 조건의 누락 검토 사유를 보완. 선택 조건 감사에서 미확정·잘못된 조건·모든 대안 잠김 각각 0건

팀원 검토 결과정원률의 화면·화풍·결과·도전 코드·NPC 검토 문서까지 통합 후보에 반영

회의에서 확인할 미완료 사항

모든 사건 이미지가 최종 승인된 상태는 아닙니다. 대표 사례로 어금니 사건의 돌잡이 그림, 돌잡이 선택 사건의 치발기 그림, 수술 상담의 육상 출발선 그림이 확인됐습니다. 돌잡이 컷신은 선택 전에 판사봉을 잡은 모습을 보여 줍니다. 실제 사진 생성은 외부 서비스 설정·네트워크에 영향을 받으므로 오늘 시연 환경의 성공 여부를 따로 확인해야 합니다.

기존의 ‘290개 미제작’ 보고는 잘못된 집계였습니다. 현재 지정 PNG가 없는 사건은 20건이며, 131건은 제작된 그림의 수정 과제입니다.

6. 검증 범위와 근거

  • 현재 콘텐츠 372사건·1,069개 선택지·1,372개 결과 분기·66결말, 자동 소사건 49건
  • 통합본 Debug 단위 테스트 256개 + Release 단위 테스트 256개 통과. Debug·Release APK 빌드 성공
  • 콘텐츠·이미지 구조·선택 조건·개연성 검사 통과. Python 회귀 테스트 42개 통과
  • 대표 12사건을 일반 화면과 작은 화면에서 실행한 이미지 경로·장면 보기 검사 2개 테스트 통과
  • 직접 이미지 검수 352장과 에뮬레이터 대표 경로 검증은 범위가 다릅니다. 전체 Android 연결 테스트의 완전 통과는 별도 확인 대상입니다.
  • 최종 개발 인수 기준에는 이미지 대기 151건 외에도 이전 선택 조건 의미 검수 기록의 변경·미검토 25항목이 남아 있습니다. 오늘은 시연용 통합본입니다.
  • Debug APK는 에뮬레이터 설치용입니다. unsigned Release APK는 직접 설치할 수 없으며 별도 서명이 필요합니다.
