## 기존 통합본과 달라진 점

### 1. 시작 화면

기존에는 시작 성향을 고르는 흐름이 중심이었다. 최신본은 시작 능력치를 주사위 두 개씩 굴려 정하고, 최대 3회 다시 굴릴 수 있다. 굴린 결과와 가장 가까운 성향을 자동으로 계산하며, 건강은 주사위 대상에서 제외한다. 성향 이름은 게임 내부 데이터의 `starter_*` 플래그와 연결된다.

### 2. 실제 사진 얼굴과 성장 외형

사진 얼굴 사용을 선택한 경우에만 얼굴 시트를 사용할 수 있도록 선택 상태와 Android 권한 계약을 추가했다. 사진 전체를 그대로 화면에 넣는 방식이 아니라 시기별 얼굴 영역을 잘라 캐릭터에 합성한다. 중년·노년에는 흰머리·주름·눈 레이어가 추가되어 나이 변화가 머리카락만 바뀌는 문제를 보완했다. 사진 기능은 사용자의 동의와 기기 권한이 전제이며, 저장소에 특정 사용자의 사진을 기본 포함하지 않는다.

### 3. 연도별 이야기와 인생 기록

선택지 결과와 별개로 시기·연도별 일상 이야기 후보를 제공한다. 이야기 템플릿은 결혼·취업·합격 같은 결과를 임의로 단정하지 않도록 작성되어 있다. 인생 기록 화면은 최신 기록이 위에 오도록 정렬하는 흐름을 지원하고, 선택 결과와 자동 진행 기록을 구분한다.

### 4. 사건 이미지 범위

기존 통합본의 승인·검수 이미지 외에 #53의 57장과 #55의 65장이 저장소에 추가됐다. 현재 `followup_20261031` 폴더에는 128개 PNG가 있고, `avatar_age` 폴더에는 성장 외형 레이어 39개가 있다. 이미지 파일이 추가됐다는 사실과 사건별 의미 검수·앱 라우팅이 완료됐다는 사실은 구분한다.

신규 이미지의 배치별 manifest와 validation 기록은 `docs/assignments/20261031/submissions/batches/` 및 신기훈 제출 manifest에 있다. 정상 게임 경로에서 사용할 이미지는 `image_routing.json`에 연결되어야 하며, 미연결 파일을 완료 수량으로 세지 않는다.

### 5. 기존 기능의 유지

건강 4색 게이지, 타이핑 중 터치 시 본문 즉시 표시, 장면 보기 전체화면과 한 번 터치 복귀, 건강 스탯 통합, 기존 저장·결말 흐름은 최신 PR 병합 후에도 유지된다. 최신 PR은 이 기능들을 제거하지 않고 시작·기록·외형·사건 이미지 범위를 확장한다.
