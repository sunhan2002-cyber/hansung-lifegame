# 5주차 테스트 케이스

## 일반 테스트

| ID | 대상 | 절차 | 기대 결과 |
| --- | --- | --- | --- |
| W5-N-001 | 앱 실행 | 앱을 실행한다. | 시작 화면이 표시된다. |
| W5-N-002 | 새 게임 | `새 게임`을 누른다. | 캐릭터 선택 화면으로 이동한다. |
| W5-N-003 | 캐릭터 선택 | 아기 1개를 선택한다. | 게임 시작 버튼이 활성화된다. |
| W5-N-004 | 게임 진입 | 게임 시작을 누른다. | 사건 화면이 표시된다. |
| W5-N-005 | 사건 데이터 | 화면에 사건 제목, 단계, 본문이 표시된다. | 빈 텍스트가 없다. |
| W5-N-006 | 선택지 | A/B 선택지가 표시된다. | 선택지 버튼을 누를 수 있다. |
| W5-N-007 | 선택 결과 | A 선택지를 누른다. | 결과 화면과 결과 문장이 표시된다. |
| W5-N-008 | 지표 변화 | 선택 결과 화면을 확인한다. | 변화한 지표가 표시된다. |
| W5-N-009 | 다음 사건 | `다음 사건`을 누른다. | 다음 사건 또는 결말로 이동한다. |
| W5-N-010 | 결말 데이터 | 결말 목록을 로딩한다. | 결말이 25개 이상이다. |
| W5-N-011 | 이미지 데이터 | 이미지 목록을 로딩한다. | 이미지 ID가 1개 이상이고 fallbackText가 있다. |
| W5-N-012 | 저장 초기화 | 저장값이 없을 때 시작한다. | 이어하기가 비활성화되거나 새 게임 안내가 보인다. |

## 위험 테스트

| ID | 대상 | 절차 | 기대 결과 |
| --- | --- | --- | --- |
| W5-R-001 | JSON 파싱 | `events.sample.json`을 파싱한다. | 예외 없이 읽힌다. |
| W5-R-002 | 사건 ID | 전체 사건 ID를 검사한다. | 중복이 없다. |
| W5-R-003 | 선택지 누락 | 모든 사건의 선택지 수를 검사한다. | 모든 사건에 2개 이상 있다. |
| W5-R-004 | 이미지 ID 누락 | 사건의 imageId와 이미지 목록을 비교한다. | 누락 목록이 없다. |
| W5-R-005 | 결말 ID | 전체 결말 ID를 검사한다. | 중복이 없다. |
| W5-R-006 | 기본 결말 | `isDefault` 결말을 검사한다. | 최소 1개 이상이다. |
| W5-R-007 | 버튼 연타 | A 버튼을 빠르게 여러 번 누른다. | 지표 변화가 중복 적용되지 않는다. |
| W5-R-008 | 깨진 저장값 | 저장 JSON 일부를 깨진 값으로 둔다. | 앱이 죽지 않고 새 게임 또는 기본값으로 복구된다. |
| W5-R-009 | 잘못된 stage | stage가 알 수 없는 값일 때 로딩한다. | 기본 단계로 안전 처리하거나 해당 데이터 검증에서 실패 처리한다. |
| W5-R-010 | 지표 범위 초과 | 지표가 -10 또는 130이 되는 선택을 테스트한다. | 화면 막대는 0~100 범위 안에서 표시된다. |
| W5-R-011 | 빈 결말 후보 | 조건에 맞는 결말이 없게 만든다. | 기본 결말로 이동한다. |
| W5-R-012 | 앱 재설치 | APK를 재설치한 뒤 실행한다. | 강제 종료 없이 시작 화면이 뜬다. |

## 애매한 사례 테스트

| ID | 대상 | 절차 | 기대 결과 |
| --- | --- | --- | --- |
| W5-A-001 | 조건 사건 없음 | 현재 단계에서 조건을 만족하는 사건이 없게 만든다. | fallback 사건 또는 결말로 안전 이동한다. |
| W5-A-002 | 결말 조건 다중 만족 | 여러 결말 조건을 동시에 만족한다. | priority가 높은 결말이 선택된다. |
| W5-A-003 | 돌발 이벤트 후보 다수 | SPECIAL 후보가 여러 개 존재한다. | 조건과 priority 기준으로 하나를 고른다. |
| W5-A-004 | imageId는 있으나 파일 없음 | 실제 PNG 파일 없이 실행한다. | fallbackText 또는 이미지 대체 영역이 보인다. |
| W5-A-005 | 긴 사건 문장 | 150자 이상 사건 본문을 표시한다. | 스크롤 또는 줄바꿈으로 읽을 수 있다. |
| W5-A-006 | 긴 선택지 | 60자 이상 선택지를 표시한다. | 버튼 밖으로 텍스트가 튀어나가지 않는다. |
| W5-A-007 | 변화량 0 | 일부 지표 변화가 0인 선택을 누른다. | 결과 화면에서 0 변화 지표는 과하게 표시되지 않는다. |
| W5-A-008 | 저장된 화면 상태 | 결과 화면 상태에서 앱을 닫고 다시 연다. | 저장 정책에 따라 결과 화면 또는 안전한 사건 화면으로 복구된다. |
| W5-A-009 | 플래그만 존재 | flags는 있으나 completedEventIds가 비어 있다. | 중복 사건 여부를 검사하고 안전하게 진행한다. |
| W5-A-010 | ADULT 이후 진행 | 성인기 마지막 사건 이후 다음 사건을 요청한다. | 결말 화면으로 이동한다. |
| W5-A-011 | fallback 사건 여러 개 | 같은 단계 fallback이 여러 개 있다. | priority 또는 안정적인 순서로 선택된다. |
| W5-A-012 | 한글/영문 지표 혼용 | JSON에 한국어 지표와 영문 지표가 섞인다. | 지원하는 지표명만 정상 반영되고 오타는 검증에서 잡힌다. |

## 제출 전 최종 명령

```powershell
./gradlew test
./gradlew assembleDebug
```

두 명령이 모두 성공해야 검증 통과로 처리한다.
