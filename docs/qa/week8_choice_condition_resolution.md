## 정책

- 단일 상승 스탯 결과는 해당 스탯의 시기별 임계값으로 조건화했다.
- 플래그·문장으로 주 능력이 분명한 다중 스탯 선택지는 의미상 주 스탯으로 조건화했다.
- 반응·연출·돌발 생존 선택지는 항상 실행 가능으로 확정했다.
- 각 사건에는 최소 하나의 항상 실행 가능한 선택지를 남겼다.
