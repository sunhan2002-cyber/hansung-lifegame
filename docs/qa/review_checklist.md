# PR 또는 커밋 전 확인 체크리스트

GitHub push 전에는 아래 항목을 Notion 카드 기준으로 먼저 확인한다.

## 공통 확인

- [ ] Notion 카드에 제출 파일 또는 ZIP이 올라왔다.
- [ ] 제출 파일명이 숙제 기준과 일치한다.
- [ ] 제출자가 작업 내용과 실행 방법을 적었다.
- [ ] 팀장이 파일을 열어 실제 내용을 확인했다.
- [ ] 검증 통과 전 GitHub에 push하지 않았다.

## JSON 확인

- [ ] JSON 파싱이 실패하지 않는다.
- [ ] 필수 필드가 누락되지 않았다.
- [ ] ID가 중복되지 않는다.
- [ ] 결말은 20개 이상이다.
- [ ] 이미지 ID는 80개 이상이다.
- [ ] 기본 결말이 1개 이상 있다.

## Kotlin 확인

- [ ] 요구 클래스와 메서드가 존재한다.
- [ ] 선택 결과가 0~100 범위를 넘지 않는다.
- [ ] 같은 사건 발생 ID가 중복 반영되지 않는다.
- [ ] 조건부 사건과 기본 결말 처리가 있다.
- [ ] Android 프로젝트 병합 후 `./gradlew test`를 실행했다.

## 완료 처리

- [ ] 팀장 검사를 통과했다.
- [ ] `./gradlew test` 또는 대체 검증 결과가 기록되어 있다.
- [ ] 필요한 경우 `./gradlew assembleDebug`를 실행했다.
- [ ] GitHub push 후 commit 링크를 Notion 카드에 남겼다.
