## 검토 지문과 기존 승인 범위

- V1: 제목·본문·선택 라벨·선택 조건·사건 종류의 기존 선택 개방성 지문. 기존 기록을 그대로 보존한다.
- V2: 위 범위와 함께 사건 발생 조건·시기·후속 사건 및 해당 선택의 모든 결과·확률·보상·플래그·이전 형식 필드를 별도 `fullSourceHash`로 묶는다. 결과만 바꾸거나 사건 발생 조건만 바꿔도 다시 검토 대기 상태가 된다.
- 새 25개에는 검토 버전·날짜·AI 검토자·검토 결과 ID·선택별 근거를 함께 남겼다. 지문만 갱신해 기존 승인을 이어 붙이지 않았다.
- 이미지 ID·그림 시점은 텍스트 의미 승인 범위에서 제외하며 별도 이미지 검수를 유지한다.

## 이미지 승인 영향

변경한 4개 사건 중 `adult_039`, `love_date_01`, `love_child_plan_01`은 이미 이미지 검수 대기 상태였다. `path_soc_05`는 기존 그림 승인이 있었으므로, 분류대장의 현재 상태를 `REVIEW_REQUIRED_CONTENT_CHANGED`로 되돌렸다. 기존 PNG·그림 SHA·기존 사건 승인 지문은 변경하지 않았다.

그 결과 텍스트 의미 검토는 25개 해소되더라도 이미지 대기는 151개에서 **152개**가 된다. 추가 1개는 새 그림 미제작이 아니라 콘텐츠 변경 후 기존 그림의 적합성을 다시 확인할 항목이다. 원본 그림 파일은 이번 작업에서 수정하지 않았다.

기존 이미지 대기 151개는 실제 라우팅 기준 151개 고유 경로다. 존재하는 131개 PNG도 SHA가 서로 달라 같은 파일 하나의 수정으로 여러 사건이 동시에 해결되는 묶음은 없다. 미존재 20개는 모두 러브라인 그림이다. 분류대장의 `preferredFileExists`는 과거 입력 스냅샷이므로 현재 제작 여부는 실제 라우팅·파일 검사를 사용한다.
