# 6주차 테스트 케이스

6주차 테스트는 일반, 위험, 애매 사례로 나누어 진행한다. 목표는 PR별 단독 검증과 최종 통합 검증에서 같은 기준을 쓰는 것이다.

## 1. 일반 테스트

| ID | 대상 | 테스트 내용 | 기대 결과 |
| --- | --- | --- | --- |
| W6-N-001 | 콘텐츠 | `events.sample.json` 파싱 | JSON 파싱 성공 |
| W6-N-002 | 콘텐츠 | `endings.sample.json` 파싱 | JSON 파싱 성공 |
| W6-N-003 | 콘텐츠 | `image_ids.sample.json` 파싱 | JSON 파싱 성공 |
| W6-N-004 | 콘텐츠 | `characters.sample.json` 파싱 | JSON 파싱 성공 |
| W6-N-005 | 사건 | 모든 사건의 필수 필드 확인 | 누락 필드 없음 |
| W6-N-006 | 사건 | 모든 사건의 선택지 수 확인 | 각 사건 선택지 2개 이상 |
| W6-N-007 | 사건 | `eventId` 중복 검사 | 중복 없음 |
| W6-N-008 | 이미지 | 사건 imageId 매칭 검사 | 누락 imageId 없음 |
| W6-N-009 | 결말 | 결말 수 확인 | 30개 이상 |
| W6-N-010 | 결말 | 기본 결말 확인 | `isDefault: true` 1개 이상 |
| W6-N-011 | 앱 실행 | 새 게임 시작 | 캐릭터/이름 설정 화면 진입 |
| W6-N-012 | 앱 실행 | 선택지 클릭 | 선택 결과 화면 표시 |
| W6-N-013 | 앱 실행 | 다음 사건 클릭 | 다음 사건 화면 표시 |
| W6-N-014 | 앱 실행 | 최소 10개 사건 진행 | 강제 종료 없음 |
| W6-N-015 | 빌드 | `assembleDebug` 실행 | 빌드 성공 |
| W6-N-016 | 테스트 | `test` 실행 | 테스트 성공 |

## 4. 자동 검증 명령

```bash
python scripts/validate_content.py
./gradlew test
./gradlew assembleDebug
```

Windows에서는 다음 명령을 사용한다.

```bash
python scripts/validate_content.py
./gradlew.bat test
./gradlew.bat assembleDebug
```

## 5. 완료 기준

- 일반 테스트 16개 기준 충족
- 위험 테스트 16개 기준 충족 또는 실패 원인 명확히 기록
- 애매 테스트 12개 기준 충족 또는 처리 방침 기록
- 총 44개 테스트 케이스가 문서화되어 있음
